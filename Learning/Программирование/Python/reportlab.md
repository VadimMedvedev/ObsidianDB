
Это библиотека для создания pdf отчётов (и возможно не только, я хз).
Устанавливается как и все:
``` bash
pip install reportlab
```

## Создание PDF файла

``` python
from reportlab.pdfgen import canvas
```

Создание в коде pdf файла

``` python
pdf = canvas.Canvas("Название файла (на компе)")
pdf.setTitle("Название документа (внутри)")
```

Базовые команды:

``` python
pdf.save() # Сохранение этого файла в директорию python
```

### Запись текста

Написать строчку:

``` python
pdf.drawString(x, y, "текст строки")
```

Координаты необычные, центр координат в левом нижнем углу и следовательно "y" идут снизу (0) вверх (+-830), а "x" идут слева (0) направа (+-600)

Настроим шрифт, все шрифты можно посмотреть в списке:
``` python
pdf.getAvailableFonts()
```
Устанавливаем шрифт и размер для следующих рисуемых строк:
``` python
pdf.setFont('название шрифта из списка', 36) # второе - размер в пикселях
```
Настройка цвета для всех последующих строк:
``` python
pdf.setFillColorRGB(0,0,255) # - синий
```

drawString рисует строку справа от указаной точки, drawCentredString нарисует так, что указаная точка будет по центру строки.

### Разделители

например просто линия

``` python
pdf.line(x1,y1,x2,y2) # Линия из (x1,y1) в (x2,y2)
```

### Целый текст

``` python
text = pdf.textBegin(40,680) # Инициализация блока текста
# также для объекта text можно применять отдельно
# методы setFont и setFillColorRGB
text.textLine("Строка которую мы добавляем в текст") 
# Итак делаем несколько раз
# Наконец
pdf.drawText(text)
```

### Таблицы

Импортируем
``` python
from reportlab.platypus import Table
```

Создаём таблицу
``` python
table = Table(data) # data - двумерный массив
```
