
Каждый [[Файлы конфигурации Terraform|корневой модуль]] должен содержать перечень используемых провайдеров. Для этого нужно объявить источник, локальное имя и версию во вложенном блоке `required providers` в блоке `terraform`.

``` HCL
terraform {
  required_providers {
    mycloud = {
      source  = "mycorp/mycloud"
      version = "~> 1.0"
    }
  }
}
```

В блоке `required providers` перечисляються все нужные провайдеры. Каждый аргумент в нём представляет из себя отдельного провайдера. Имя аргумента будет локальным названием этого провайдера только в этом модуле, оно может быть любым. Значением этого аргумент будет объект с элементами:
* source - адрес на провайдер, который будет использоваться
* version - ограничения версии, какой именно версии провайдер будет скачен.

### Адреса

Каждый адрес имеет вид `[<HOSTNAME>/]<NAMESPACE>/<TYPE>`, в котором часть в \[\] необязательна.
* Hostname это сервер, который предоставляет провайдеров. По умолчанию это публичный Terraform Registry.
* Namespace может иметь разный смысл в разных хранлищах, но обычно представляет из себя название организации, которая произвела данный провайдер (одна организации может сделать несколько провайдеров).
* Type это сокращённое название платформы, для которой этот драйвер был сделан.

### Версии

Аргумент `version` опциональный, если его пропустить, то terraform выберет любую версию нужного провайдера. Хотя строго рекомендуется всё же указывать необходимую версию.

Указание на выбор версии записывается в виде строки, где несколько условий записываються через запятую. Каждое условие состоит из оператора и номера версии.
``` HCL
version = ">= 1.2.0, < 2.0.0"
```
В данном примере мы будет требовать версию больше или равную 1.2.0, но строго меньшую 2.0.0

| Оператор               | Действие                                             |
| ---------------------- | ---------------------------------------------------- |
| =, отсутсвие оператора | Требует только одну единственную версию              |
| !=                     | Всё кроме этой версии                                |
| >, >=, <, <=           | Больше/меньше какой-то версии (или равно)            |
| ~>                     | Позволяет использовать только версии того же порядка |
* `~> 1.0.4`, позволяет использовать и версии по типу `1.0.10`, но не `1.1.4`.
* `~> 1.1` позволяет использовать версии по типу `1.5`, но не `2.0`

Терраформ будет использовать версии, которые подходят по всем объявленным условиям. Если такая версия не скачена, то он найдёт самую новую из подходящих и скачает её. Если версий подходящих условию нет, то он не позволит произвести любую из операций.
