
### Понятие ресурса

В терраформ **ресурсом** называется любой объект с которым мы хотим взаимодействовать. Это могут быть виртуальные машины, docker контейнеры, и т.д. Вообщем всё, из чего можно выстроить инфраструктуру.
**Провайдеры** это плагины, которые создаются для тех или иных платформ, для управления объектами в них.

### Описание ресурсов

Описание ресурсов происходит в конфигурационных файлах. Для этого используються специальные блоки `resource`.

### Настройка рабочей среды

Для того, чтобы terraform мог отслеживать инфраструктуру в проекте, нужно настроить рабочую среду и устнаовить нужных провайдеров и модули.

Перед первым примением конфигурации всегда надо [[Инициализация рабочей директории|инициализировать рабочую директорию]].

### Применение конфигурации

После команды `terraform apply` произойдут следующие дестйвия:
* Новые ресурсы, которых нет в старом state файле, создадутся.
* Ресурсы которые мы удалили, т.е. terraform видит их в state файле, но не видит в новом конфигурационным файле, будут удалены.
* Измения к уже существующим ресурсам применятся.
* Если API платформы не позволяет произвести некоторые изменения над объектом, то объект будет пересоздан с новыми настройками.
* Обновление state файла.
