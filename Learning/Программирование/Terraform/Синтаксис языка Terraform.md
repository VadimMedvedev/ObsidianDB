
Синтаксис, используемый в [[Что из себя представляет язык Terraform?|языке terraform]], носит название **HCL (HashiCorp  Language)**. Хотя, любой конфигурационный файл может быть записан и в json формате, но HCL более удобен для чтения. Хотя json легче парсить.
Тут представлены только оснвные его конструкции.

### Аргументы и блоки

Аргумент представляет из себя имя со связанным с ним значением:
``` HCL
image_id = "abc123"
```
Слева от знака равно ставится название аргумента, а справа его значение.

Блок - это некоторый контенер, хранящий аргменты и другие блоки:
``` HCL
resource "aws_instance" "example" {
  ami = "abc123"

  network_interface {
    # ...
  }
}
```
Блок имеет **тип** (в данном примере, тип: `resource`). Для каждого типа блоков, необходимо своё количество **лейблов**, которые мы записываем после него. После этого идёт тело блока, заключённое между фигурными скобками. В нё указываются соотвествующие этому типу блоков аргументы и вложенные блоки.

### Комментарии

Виды комментариев:
* `#` однострочный комметарий. После него, terraform не будет читать
* `//` тоже однострочный комментарий
* `/*` и `*/`  используються для многострочных комментариев. Текст между ними не будет читаться.
