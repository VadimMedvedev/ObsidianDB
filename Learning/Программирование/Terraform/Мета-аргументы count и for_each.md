
По умолчанию, такие блоки как `resource`, `module`, `data` и т.д. Создают только один экземпляр определяемого объекта. Используя мета-аргумент `count` можно создать сразу несколько объектов описанных одним набором аргументов.

### Использование

Аргумент `count` принимает целое положительное число, и создаёт такое количество образцов объекта. Каждый из созданных объектов - отдельная сущность, которая самостоятельно удаляется, обновляется, создаёться и т.д.
Далее, в теле объявляемого объекта, можно будет обращаться к индексу данной машины (индексация от нуля) используя `count.index`.
Затем, обращение к конкретном объекту будет происходить по индексу как `<TYPE>.<NAME>[<INDEX>]`.

### Мета-аргумент for_each

Аргумент `for_each` работает аналогично `count`, только он создаёт копию объекта для каждого элемента отображения или множества.
Примеры:
``` HCL
resource "azurerm_resource_group" "rg" {
  for_each = tomap({
    a_group       = "eastus"
    another_group = "westus2"
  })
  name     = each.key
  location = each.value
}
```
и
``` HCL
resource "aws_iam_user" "the-accounts" {
  for_each = toset(["Todd", "James", "Alice", "Dottie"])
  name     = each.key
}
```

Здесь функции `tomap` и `toset` создают отоюражение и множество из словаря и множества соотвественно. Заметим, что в множестве каждый элемент это просто значение `key`, а в отображении также для каждого `key` мы прописываем своё значение `valuse`.
Для обращения к ключу в теле мы используем `each.key`, и если мы используем отображение. то для обращения к значению используем `each.value`.
Мы можем обращаться к этим объектам через ключи `<TYPE>.<NAME>[<KEY>]`.

При этом, очевидно, все ключи должны быть заранее определены (константы), а значения могут варьироваться.
