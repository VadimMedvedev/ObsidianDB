
Есть несколько состояний в vim:
1) Normal - мы в нём находимся по дефолту, в нём можно вводить простые команды
2) Insert - в нём можно править текст как в обычном текстовом редакторе
3) Command - можно вводить сложные команды, макросы

### Режим Normal

Переход в другие режимы:
* i, a - переход в режим insert
* : - переход в режим command
* ZZ - сохранить и выйти
* u - отменяет последнее изменение. Наимая ещё, будем откатываться к предыдущим измениям дальше. По сути ctrl + z.
* G - переносит на последнюю строчку курсор
* gg - перенос курсора в начало
* r + <символ> - заменяет символ в месте где стоит курсор, на второй напечатанный символ.
* R - переходит в режим замены, все написанные символы будут писаться сверху, для выхода нажимаем escape.
* x - удаление символа, где стоит курсор
* dw - удаляет слово начиная с симола, на котором мы стоим (по сути удаляет всё до следующего пробела включительно, или другого разделяющего символа)
* v - переход в визуальный режим. Выделение начинается с места, где мы нажали v, и мы тянем курсор, выделяя дальше.
* V - выделяет сразу целыми строками.
* p - вставляет из буфера обмена место курсора строку или же строчки.
* "<буква>p - вставляет из буфера обмена соответсвующего этой букве

### Режим Command

Промпт будет выглядеть как ":".
Чтобы выти обратно в режим Normal нажимаем backspace.

Команды:
* q - выйти. Если были внесены изменения, то поругается.
* q! - выйти без сохранения, принудительно
* w - сохранить изменения
* wq, x - сохранить и выйти

### Режим Insert

Для возвращения в режим Normal нажимаем escape.

### Визуальный режим

* y - копируем выделенное в буффер обмена
* "<буква>y - копирует в буфер обмена соответсвующий этой букве

### Поиск

Для поиска, в нормальном режиме нажимаем / и вбиваем слово для поиска.
* enter - перейти к первому вхождению
* n - перейти к следующему
* N - перейти к предыдущему

### Многооконный режим


Также, vim может превращаться в многооконный текстовый редактор:
* :split <файл> - разделяет экран попалам по горизантали, и открывает в верхнем окне указанный файл
* :vsplit <файл> - тоже самое, но делет по вертикали, и открывает в правом окне

Эти окна можно продолжать делить и дальше.
Для переключения между окнами зажимаем ctrl + w + <кнопка курсора: h,j,k,l>. Простой переход к следующему окну ctrl + w + w.

### Настройки vim

Есть некоторые фишки, которые можно включать и отключать в vim, например:
* :set number - включает нумирацию строк
и т.д.

Для того, чтобы каждый раз это не прописывать, можно использовать файл .vimrc.

Такой файл есть общий, а также и для каждого пользователя в его домашней директории. В нём лежат стандартные настройки vim. Если у пользователя нет в домашней директории файла .vimrc, то настройки будут применены из общего файла. Если и его нет, то вим будет стандартным.
Например в .vimrc можно сразу записать set number, и при каждом запуске vim, строчки будут автоматически подсвечиваться.
