
HTTP это протокол для передачи гипертекста в формате HTML.
После ввода URL (универсального указателя ресурса) веб браузер устанавливает соединение по протоколу http с сервером и получает от него файл html который отображается в окне браузера.

мы прописываем url адрес, он состоит из трёх частей:
1. протокол передачи
2. сервер
3. ресурс на сервере с которым мы связываемся
Пример: `https://ru.wikipedia.org/wiki`

HTTP + secure = HTTPS - усовершенствованный протокол использующий шифрование и аутентифика.

Этот протокол работает на просто механизме "запрос-ответ".
Есть несколько стандартных типов сообщения, основные:
* GET - запрос данных клиентом
* POST - выгрузка файлов данных на веб-сервер
* и т.д.
Каждый веб сервер самостоятельно реализует эти типы обращения к его ресурсам.
