
Протокол динамической настройки узлов. Т.е. при помощи него мы можем не париться и получать каждый раз ip адрес динамически, т.е. автоматически.
Т.е. они автоматически настраивают конфигурации узлов, выдавая им ip адреса, маску подсети и адрес шлюза по умолчанию.

В сети есть DHCP сервера, которые хранят свободные и занятые ip адреса в локальной сети. Они выдают адреса на время, и когда время истекает dhcp возращает занятый адрес обратно в пул свободных адресов. Также на нём можно настраивать и статические адреса.

Диалог клиента и сервиса выглядит так:
1) DHCPDISCOVER - клиент просит выдать ip адрес. Этот запрос может прийти нескольким DHCP серверам (т.к. отправляется бродкастно, мы не знаем адрес DHCP изначально, если не настроено).
2) DHCPOFFER - сервер предлагает возможность взять ip
3) DHCPREQUEST - согласие на использование. Нужно для того, чтобы нужный DHCP сервер понял что именно у него взяли ip.
4) DHCPACK - Согласие от сервера.

После выдачи ip адреса, клиент, для продления использования своего адреса, обращается где-то через половину времени аренды к DHCP серверу о продлении адреса.

DHCPv6 предлагает те же услуги но для IPv6 адресов.

Практически любое устройство L3 может работать как dhcp сервер.
