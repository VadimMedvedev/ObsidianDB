
`ip nat {inside | outside}`  - настраивает интерфейс (в настройках которого мы находимся) на работу NAT. inside - интерфейсы смотрящие во внутренние сети, outside во внешние. Обязательно надо указывать, без этого механизм NAT не работает.
`ip nat translation timeout <время в секундах>` - сколько хранить каждую запись о трансляции (динамический NAT или PAT) (по умолчанию 24 часа - много, память может забится)
`clear ip nat translation` - удаляет записи всех динамических преобразований

`show ip nat translation` - показывает все активные трансляции (статические всегда отображает)
`show ip nat translation verbose` - более подробная информация
`show ip nat statistics` - показывает информацию о интерфейсах на которых работает NAT и статистику по переданным пакетам.

`ip nat inside source static <серый адрес> <белый адрес>` - настройка [[Технология NAT|статического преобразования]]. Указываем какой серый адрес будет транслироваться в белый.

`ip nat pool <название> <адрес начало> <адрес конца> netmask <маска подсети>` - мы создаём пул доступных нам белых адресов (через диапозон указывая начальный и конечный адрес). Диапозон не обязан полностью заполнять сети указанной маски.
`ip nat inside source list <номер> pool <название>` -  здесь мы указываем настройки [[Технология NAT|динамического преобразования]]. Для этого надо заранее создать [[ACL списки|ACL список]] который будет говорить, какие пакеты из inside интерфейсов мы будем транслировать (все они должны проходить фильтрацию с permit). А также мы указываем заранее созданый пул адресов, в который мы будем транслировать серые адреса.

`ip nat inside source list <номер> {pool <название> | interface <название>} overload` - в отличие от предыдущей настраивает не динамический NAT, а [[Технология NAT|PAT]]. Также можно использовать пул адресов, или один конкретный интерфейс.
