
`hostname <название>` - меняет название устройства (в режиме глобальной конфигурации).
`banner motd <символ>` - предлагает написать вступительное сообщение, оканчиваем его символом заданным в аргументе. Это сообщение будет показываться при каждом подключении к консоли. motd - message of the day.

##### Настройка времени
`show clock` - выводит текущее время и дату
`clock set hh:mm:ss <1-31> Mon <1993-2035>` - установка времени, даты, месяца и года.
##### Настройка беопасности
Эти команды надо выполнять в [[Режимы работы в IOS|режиме глобальной конфигурации]].
`enable password <пароль>` - меняет пароль для привелегированного пользователя (из conf). Не безопасно, в running-config храниться прямо так.
`enable secret <пароль>` - тоже меняет пароль, но на устройтве он будет храниться в зашифрованном виде, что + к безопасности. При наличии обоих паролей, только по этому будет осуществляться вход.
`line console 0` - переход в настройку консоли 0 (из config)
`line vty 0 15` - переход в настройку vty линий (всех) (из config)
`password <пароль>` - установление пароля на линии vty и консоли
`login` - команда говорит, чтобы пароль запрашивался (у кого - зависит от режима работы, просто config или определённая линия/терминал)
`service password-encryption` - шифрует все явно заданные пароли в running-config (т.е. заданные командой enable password и password).
`security passwords min-length <число>` - устанавливает минимальную длину пароля, которую можно установить
`login block-for <секунды> attempts <число> within <секунды>` - настройка блокировки подключения на некоторое время при достижении указанного числа неудачных попыток ввода пароля в течении указанного времени. Это сильно замедляет процедуру подбора пароля (брутфорс).

##### Настройка интерфейсов и прочего
`show running-config` - показывает [[Маршрутизаторы изнутри|текущую конфигурацию]].
`show startup-config` - аналогично показывает загрузачную конфигурацию. Но изначально её нет. 
`copy running-config startup-config` - копирование файла running-config в файл startup-config. По сути теперь вся наша скопированная текущая конфигурация будет загружаться при каждом запуске устрйоства, т.е. мы сохранили конфиги.
