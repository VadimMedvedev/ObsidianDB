
`ip dhcp excluded-address` - указываем адреса которые мы не будем выдавать. Если указана два адреса, то это диапозон. Если он один, то это один адрес для исключения. Можно делать несколько раз подряд, чтобы задать особую настройку.
`ip dhcp pool <название>` - название пула адресов. Заходим в настройки этого пула
`network <адрес сети> <маска подсети>` - определяем адрес в настройках пула, теперь адреса для этой сети будут выдаваться
`default-router <адрес>` - указываем адрес шлюза по умолчанию, который будет выдаваться (в режиме настройки пула)
`dns-server <адрес>` - адрес dns сервера, который будет выдаваться (в режиме настройки пула)
`domain-name <доменное имя>` - доменое имя устройства
`show ip dhcp binding` - показывает все выданные адресы и кому.
`show ip dhcp pool` - показывает все настроеные пулы, сколько адресов выдали и т.д.

`ip helper-address` - указывается в настройках интерфейза маршрутизации, для передачи бродкастных сообщений с этого интерфейса на этот адрес. Это как раз сделано, чтобы компы из одной сетки, могли достучаться до dhcp сервера 
`debug ip dhcp server events`
`show ip dhcp conflict` - показывает адреса, которые мы не выдавали, но он есть в сети (либо статически был настроен, либо выдан другим сервером)
