``
`router ospf <номер процесса>` - создание процесса ospf для маршрутизатора. В основном для всех маршрутизаторов используется один и тот же номер. Таким образом мы инициализируем использование ospf. После этой команды мы переходим в настройку ospf.
`router-id <номер ID>` - самостоятельно даём номер маршрутизатора. Он нужен для определния DR в каждой локальной сети и определения приоритета при обмене данными. По умолчанию используется адрес обратной петли, если его нет, то наибольший адрес на интерфейсах.
`interface Loopback <номер>` - переход в настрйки обратной путлию. В ней как обычно можно задать адрес обратной путли (команда `ip address`). Полезно не только для OSPF, но и для многих других протоколов. Этот интерфейс не падает.
`network <адрес сети> <шаблон маски> area <номер области>` - используется для опеределения в каких сетях и на каких соответственно интерфейсах будет использоваться протокол OSPF. Можно объявлять несколько раз. Шаблонная маска работает как и в [[ACL списки]] (т.е. 1 - биты которые мы игнорируем, 0 - которые смотрим). Если используется только одна области, то указываем на всех маршрутизаторах `area 0`.
`ip ospf <номер процесса> area <номер области>` - в настройках интерфейса сразу настраивает весь интерфейс на работы с нужным OSPF процессом.
`passive-interface <интерфейс>` - в настройках ospf используется для установление пассивного интерфейса. В сторону пассивных интерфейсов не происходит настройки OSPF протокола, но об этой сети можно сообщать другим маршрутизаторам.
`ip ospf network point-to-point` - объявляем в настройках интерфейса, что подключение происходит напрямую к маршрутизатору, а значит необходимости выбора DR и BDR не будет.
`ip ospf priorite <0-255>` - назначение [[Протокол маршрутизации OSPF|приоритета]] на интерфейсе.
`auto-cost reference-bandwidth <число>` - определяет максимальную скорость среди интерфейсов, чтобы относительно неё высчитывать метрику. Она измеряется в гигабайтах, поэтому для 10 гигабайт указываем значение 10000.
`ip ospf const <значение>` - вручную задаём стоимость на интерфейсе.
`ip ospf {hello-interval | dead-interval} <секунды>` - указание соответствующих интервалов на интерфейсе. Но надо настраивать эти параметры на обеих концах

`show ip ospf neighbor` - показывает всех соседей маршрутизатора
`show ip ospf database` - показывает [[Протокол маршрутизации OSPF|LSDB таблицу]]
`show ip route` - можно увидеть маршруты настроенные при помози OSPF.
`show ip ospf interface <название>` - показывает настройку интерфейса для ospf
