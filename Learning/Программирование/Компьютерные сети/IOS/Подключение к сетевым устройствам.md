
### Подключение по кабелю

Консольный порт является обязательным элементом практически всех профессиональных сетевых устройств Cisco (но на обычных потребительских устройствах его может и не быть) — маршрутизаторов, коммутаторов, межсетевых экранов и беспроводных контроллеров. Даже если устройство не имеет других портов, консольный порт для управления присутствует всегда.
Обычно физический порт имеет разъём:
* RJ-45 - классический
* mini-USB - обычно встречается вместе с классическим RJ-45 на современных устройствах

Круто если на нём mini-USB, тогда можно подключиться просто по проводу USB - mini-USB. Тогда можно легко подключить.

Надо скачать приложение для работы с терминалом. На LInux например minicom.
При соединении надо указать speed (baud rate) обычно 9600, но иногда и нет, надо узнавать в документации (если не верно ввести не будет работать). Ну и другие параметры.

### Через ssh или telnet

Для этого есть vty линии - это виртуальные "двери" для подключения (Virtual Teletype). Сколько на устройстве есть этих линий, столько к нему одновременно смогут подключиться программистов. Они нумируються с нуля и их обычно либо 5, либо 16.
