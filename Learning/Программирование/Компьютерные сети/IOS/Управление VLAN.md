
Создание и настройка vlan происходит в режиме глобальной кофигурации.
`vlan <номер>` - создание [[VLAN сети|vlan]] с заданным id. После этой команды мы заходим в режим конфигурации этого vlan.
`no vlan <номер>` - соответветсвенно удаляет vlan с таким id.
`name <название>` - указываем уникальное имя для vlan (делается в режиме этого vlan).

Чтобы настроить некоторый порт для работы с vlan используються следующие команды:
`interface <id интерфейса>` - переходим в настройки нужного порта
`switchport mode access` - этой командой, мы говорим коммутатору, что к этому порту подключено оконечное устройство, это не [[Транки VLAN|транк]]. При отправки туда кадра [[Тегирование кадров в сетях с VLAN|тег]] убирается, и при получении с него на оборот надевается. Оно по этому порту вообще ожидает не тегированный трафик.
`switchport access vlan <номер>` - указывает тег какого vlan будет прикрепляться к кадрам приходящим на этот порт.
`no switchport access vlan` - порт перестаёт работать в режиме vlan, теперь он обычный порт.
`switch mode trunk` - перевод порта в режим транка (магистрали).
`switchport trunk native vlan <номер vlan>` - при переходе через транк мы должны как-то окрасить нетегированный трафик, мы придаём ему специальный, не используемый vlan. Этот номер должен быть одинаковым на обоих портах магистрали. После перехода, с нетегированного трафика снимается этот временный тег.
`switchport trunk allowed vlan <список,номеров,vlan>` - список из vlan которые мы разрешаем передовать по этой магистрали.
`no switchport trunk native vlan` - теперь все кадры имеют доступ к этому каналу связи (vlan не важен).
`no switchport trunk allowed vlan` - работа с нетегированным трафиком теперь не проводится.

Просмотр информации по vlan из привелегированного режима EXEC можно сделать при помощи команды:
`show vlan name <название vlan>`
