
`spanning-tree mode <протокол>` - можно выбрать конкретный протокол STP (RSTP, PVST и т.д.).
`spanning-tree vlan <номер> root primary` - устанавливаем коммутатор как корневой узел для этого узла (если используется pvst)
`spanning-tree vlan <номер> root secondary` - устанавливаем коммутатор как вспомогательный корневой узел для этого узла (если используется pvst)

В настройке интерфейса которое напрямую подключено к оконечному устройству можно использовать режим portfast, которые сразу начинает пересылку, пропуская этам прослушивания и обучения.
`spanning-tree portfast` - настройка режима portfast в настройках соответсвтующего интерфейса
`spanning-tree bpduguard enable` - запускает защиту bpdu. Т.е. если начинает получить bpdu сообщения на порту (скорее всего от коммутатора), то блокирует этот порт.
