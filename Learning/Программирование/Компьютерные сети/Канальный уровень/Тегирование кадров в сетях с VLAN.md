
Тегирование кадра - это процесс добавления в заголовок кадра дополнительное поле, которое идентефицирует принадлежность его к некоторой сети VLAN.
Затем этот заголовок используется маршрутизаторами для передачи кадра.

Тегирование всегда происходит при отправке кадра через [[Транки VLAN|магистраль (транк)]]. При пересылке через не магистральные порты, этот тег удаляется.
Другими словами все порты настроенные для работы с VLAN транком готовятся к получению кадра принадлежащего к какой-то VLAN, и соответсвенно с добавочным поле для тега.
