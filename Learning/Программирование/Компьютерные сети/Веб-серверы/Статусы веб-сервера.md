
В HTTP используются коды состояния ответов. Это трёхзначное число, которое сервер возвращает в ответе в первой строке. Оно показывает был ли запрос успешным или нет.

В основном все коды состояний делятся на пять классов, это определяется по последней цифре в числе:
* `1xx` - запрос получен, процесс продолжается
* `2xx` - успех, сервер успешно получил, понял и обработал запрос
* `3xx` - перенаправление, т.е. для выполнения запроса необходимы дальнейшие действия со стороны клиента
* `4xx` - ошибка в запросе клиента
* `5xx` - сервер не смог выполнить запрос

Примеры конкретных кодов статусов:
* `102` - сервер продолжает обрабатывать запрос
* `200` - ОК, всё хорошо
* `201` - ресурс успешно создан
* `301` - ресурс перемещён на всегда на новый URL. Он указывается в заголовке Location.
* `302` - времено переехал. По сути тоже самое, но браузер может делать выводы по особому себя ввести
* `404` - ресурс не найден
* `403` - запрещено для пользователя
* `500` - внутреняя ошибка
* `502` - прокси получил неверный ответ от backend сервера.
