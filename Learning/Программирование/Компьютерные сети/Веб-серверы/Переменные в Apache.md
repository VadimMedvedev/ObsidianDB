
В процессе работы Apache создаются различные переменные, которые можно использовать для настройки его работы.
Все переменные пишутся заглавными буквами, и чтобы получить их значения используется конструкция `%{VAR_NAME}`.

### Основные группы переменных

##### А. Заголовки запроса (HTTP Headers)
Любой заголовок, пришедший от клиента, доступен через префикс `HTTP_`.
- **Синтаксис:** `%{HTTP_ИМЯ}`
- **Примеры:**
    - `%{HTTP_HOST}` — домен (из заголовка `Host`).
    - `%{HTTP_USER_AGENT}` — браузер/бот.
    - `%{HTTP_REFERER}` — страница, с которой перешли.
    - `%{HTTP_COOKIE}` — куки.
    - `%{HTTP_X_FORWARDED_FOR}` — реальный IP, если за прокси.

##### Б. Внутренние переменные Apache
Они формируются самим сервером.
- `%{REQUEST_URI}` — путь запроса (например, `/catalog/item/1`). Включает query string (`?id=5`).
- `%{REQUEST_FILENAME}` — **Полный путь к файлу на диске** (например, `/var/www/site/catalog/item/1`).
- `%{DOCUMENT_ROOT}` — корневая папка сайта (из директивы `DocumentRoot`).
- `%{REQUEST_SCHEME}` — `http` или `https`.
- `%{HTTPS}` — `on` или `off` в запросе (не на сервере).
- `%{REMOTE_ADDR}` — IP адрес клиента.
- `%{SERVER_PORT}` — порт (80, 443).
- `%{TIME_YEAR}`, `%{TIME_MONTH}`... — текущее время сервера.

##### В. Переменные окружения (Environment Variables)
Их можно создавать вручную.
- Через директиву `SetEnv` в конфиге.
- Через флаг `[E]` в `RewriteRule`.
- Доступны как `%{ENV:ИМЯ}`.

Посмотреть все переменные можно здесь: https://httpd.apache.org/docs/current/mod/mod_rewrite.html?spm=a2ty_o01.29997173.0.0.3ba65171NEtyV5#rewritecond.
