
### Передача с известной длиной

Сервер отправляет клиенту ответ с заголовком `Content-Length` в котором указывает размер передаваемых данных в байтах. Потом идёт всё тело ответа.

Это простой способ передачи данных, но для него заранее нужно знать размер сообщения.

### Передача частями

Когда размер заранее не известен, например сообщение генерируется в течении некоторого времени и не известно скольк займёт, тело ответ разбивается на чанки которые передаются по частям.
Для этого сервер в заголовке `Transfer-Encoding` помечает тип передачи данных как `chunked`. Теперь работа осуществляется так:
* Данные разбиваются на фрагменты (чанки)
* При отправке, перед каждым чанком ставится его размер
* После отправки последнего чанка сервер отправляет чанк нулевого размера, что сигнализирует конец.

Это тяжелее парсить клиенту, но иногда такой способ просто необходим.
