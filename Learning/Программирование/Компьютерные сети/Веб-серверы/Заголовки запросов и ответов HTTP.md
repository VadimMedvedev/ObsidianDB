
В каждом запросе и ответе HTTP фигурируют заголовки. Они определяют некоторую мета-информацию о запросе/ответе. Это простые пары "имя-значение" которые распологаются между стартовой строкой и телом сообщения.
Каждый заголовок заисывается просто:
```
Имя_заголовка: значение
```
Например:
```
Host: example.com
Content-Type: application/json
...
```
После этого идёт пустая строка и начинается данные.
Сами имена заголовков не зависят от регистраю.

Некоторые важные заголовки:
* `Host` - обязательный в запросе пользователя, несёт доменное имя и порт по которому обратился пользователь
* `Origin` - источник запроса (для CORS)
* `User-Agent` - информация о клиенте, например браузер
* `Cache-Control` - правила кэширования
* `Via` - информация о проксировании
* `Connection` - управление соединением (например `keep-alive` или `close`)
* `Accept` - принимаемые типы данных
* `Accept-Charset` - поддерживаемая кодировка
* `If-Modified-Since` - получить, если изменялся после указанной даны
* `Range` - получить данные из указанного диапозона
* `Content-Length` - длина тела запроса
* `Content-Type` - тип тела запроса
* `Set-Cookie` - установка куки на клиенте
* `Cookie` - отправка куки клиентом
* `ETag` - уникальный тег версии ресурса
* `Access-Control-Allow-Methods` - разрешённые методы (для CORS)

###  Нестандартные заголовки

Кроме стандартных заголовков, которые описываются протоколами и используются всеми клиентами и серверами, можно создать ещё сугуба свои, личные заголовки, для передачи дополнительной мета информации.
Все такие заголовки должны начинаться с `X-`, чтобы отличать их от стандартных
Примеры:
```
X-RateLimit-Limit: 100
X-Ratelimit-Remaining: 95
X-Powered-By: PHP/8.4
...
```
