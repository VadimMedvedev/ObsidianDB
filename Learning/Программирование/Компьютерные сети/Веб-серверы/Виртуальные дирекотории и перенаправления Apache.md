
### Директива Alias

Через команду можно "примонтировать" виртуально директиву с сервера к директории сайта. (Только надо ещё не забыть открыть к этой директории доступ)
```
Alias "/images" "/var/www/storage/images"
```

Теперь обращаясь к ресурсу `/images` нас будет перенаправлять в указанную директорию, хотя в URI это не будет так отображаться. Короче как при монтировании.

### Перенаправление Redirect

Стандартная пересылка очень простая, мы указываем с какого ресурса мы будем пересылать на какой:
```
Redirect /old-page /new-page
```
Также существует постоянный редирект:
```
Redirect premanent /old-page /new-page
```
Это влияет только на возращаемый код:
* 301 - **(Moved Permanently)** — «Переехало навсегда». Запомни новый адрес и больше не приходи по старому.
* 302 - **(Found / Moved Temporarily)** — «Временно находится по другому адресу». Зайди по новому адресу сейчас, но в следующий раз снова спрашивай старый.
Хоть нам может показаться это фигнёй, но некоторые сайты, браузеры, системы используют эти коды для работы. Лучше указывать правильней
Можно также использовать более однозначые команды `Redirect 301` и `Redirect 302`.

### AliasMatch и RedirectMatch

Эти две команды используют регулряные выражения для перенаправления. Таким образом, любые файлы подпадающие под шаблон будут перенаправлены, подменены.

Спецсимволы:
* `.` - любой одиночный символ
* `?` - предыдущий символ 0 или 1 раз
* `*` - предыдущий символ 0 или больше раз
* `+` - предыдущий символ 1 или больше раз
* `^` - начало строки
* `$` - конец строки
* `(word1|word2|...|wordn)` - или
* `[a-z]` - диапазон
* `\` - символ экранирования, чтобы например использовать `.` в URL правильно.
* `\d` - любая цифра, `\w` - буква, цифра или \_, `\s` - пробельный символ, табуляция
Особая фишка: группа захвата `()`. Всё что будет выделенно в круглые скобки, потом можно будет использовать в перенаправлении, через `$1`, ко второму `$2` и т.д. до `$9`.

Примеры:
```
# Все URL /assets/... перенаправляются в /var/www/shared/
AliasMatch "^/assets/(.*)$" "/var/www/shared/$1
# Редирект с регулярным выражением
RedirectMatch 301 ^/articles/(\d+)$ /posts/$1
```

Заметим, что после RedirectMatch нужно указывать код перенаправления (301 или 302).

### ScriptAlias для CGI

Команда аналогична всем предыдущим
```
ScriptAlias "/cgi-bin" "/usr/lib/cgi-bin"
```

Но! Её отличие в том, что она говорит:
	_Запускай все файлы в этой директории как скрипты, а не отправляй как файлы_
Таким образом код не с секретными данными не передастся пользователю как другие картинки, заместо этого он выполнится и вернёт результат.
Более того, этат Alias автоматически настраивает исполнение скриптов в директории с этими исполняемыми файлами
