
Для того чтобы изменить стандартные, возвращаемые пользователям страницы, соответсвтующие кодам ошибок, в Apache есть директива `ErrorDocument`, которая прописывается для каждого виртуального хоста отдельно (т.е. настройки на разных сайтах будут отличаться).

```
ErrorDocument 404 "Страница не найден"
ErrorDocument 403 https://example.com/forbidden.html
ErrorDocument 500 /errors/file.html
```
Как видно, для каждой ошибки мы отдельно расписываем возвращаемый пользователю результат.
Как видно, это может быть простое сообщение (пример 1), перенапрвление на внешний сайт (пример 2) или же внутренний ресурс сайта (пример 3).
