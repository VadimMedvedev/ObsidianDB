
Для включения стандартных типов достаточно включить модуль mime:
``` bash
a2enmod mime
```

По сути, этот модуль говорит, какой MIME тип преписывать в значение `Content-Type` при отправке того или иного файла, основываясь на его формате. Конфигурационный файл модуля содрежит тону стандартных соответствий между расширениями и MIME типами.
Новые типы можно добавить легко и самостоятельно:
```
AddType application/json .json # определять файлы *.json этим типом
ForceType application/octet-stream # принудительно присваивает тип
```
Первая директива прописывается обычно в общем файле конфигурации, а вторая в контейнерах по типу `<Directory>` или `<Files>`.
Где необходимо, можно указать также используемую кодирвоку:
```
AddCharset utf-8 .html .css .js .php
```
