
Для включения и выключения дополнительных конфигураций, сайтов и модулей, используются похожие команды:
``` bash
a2ensite <название-сайта> # включение сайта
a2dissite <название-сайта> # выключение сайта
a2enmod <название-модуля> # включени модуля
a2dismod <название-модуля> # выключение модуля
a2enconf <название-конфигурации> # включени конфигурации
a2disconf <название-конфигурации> # выключение конфигурации
```

По сути, они создают символические ссылки из директорий `available-*` в директории `enabled-*` (см. [[Структура конфигурационных файлов Apache]]).
