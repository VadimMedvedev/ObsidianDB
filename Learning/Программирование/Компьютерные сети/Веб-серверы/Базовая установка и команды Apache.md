
Установить сервер apache очень просто
``` bash
apt install apache2 # пример для Debian/Ubuntu
```

Теперь достаточно его запустить. Это как обычно делаеся через systemctl:
``` bash
systemctl start apache2
```
Также не стоит забывать про важные команжы systemctl:
* `status` - посмотреть текущий статус
* `stop` - остановить службу
* `restart` - полная перезагрузка службы
* `reload` - обновление конфигурации

**Да, при каждом изменении конфигурации, надо перезагружать службу.**
