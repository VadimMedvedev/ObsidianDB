
Структура конфигурации выглядит следующим образом:
```
/etc/apache2/ 
├──apache2.conf # Главный конфигурационный файл 
├──ports.conf # Настройка портов (80, 443) 
├──envvars
├──conf-available/ # Доступные дополнительные конфигурации 
├──conf-enabled/ # Включенные конфигурации 
├──mods-available/ # Доступные модули 
├──mods-enabled/ # Включенные модули 
├──sites-available/ # Доступные виртуальные хосты 
└──sites-enabled/ # Включенные виртуальные хосты
```

каждой директории `*-available` соответствует `*-enabled`. В available директориях лежат все файлы конфигурации, которые у нас есть, а в enabled [[Символические и жёсткие ссылки|символические ссылки]] на те, которые мы в данный момент используем. Во всех них лежат такие же конфигурации, как и в файле `apache2.conf`, более того в этом файле можно увидеть что все они подтягиваются. Вобщем такое разделение сделано только для наглядности, а так синтаксис во всех этих файлах один и тот же.
В файле envvars пишутся скрипт для установки переменных окружения, которые затем используются в написании конфигурации apache2.conf.

В директориях `conf-*` лежат дополнительные конфигурации самого Apache. 
В директориях `mods-*` лежат конфигурации двух типов: `.load` в которых написано какой конкретно модуль нужно подгрузить, и `.conf`, в которых прописываются дополнительные конфигурации при установке этого модуля. 
В директориях `sites-` лежат сами конфигурации сайтов (их может быть несколько).
