
### Настройка пользователей

Для настройки пользователей удобно использовать утилиту `htpasswd`, которую можно установить из пакета:
``` bash
apt install apache2-utils
```

Теперь пользователей можно легко создавать одной командой:
``` bash
# Создать файл и первого пользователя
htpasswd -c /путь/до/файла/с/паролями user_name
# Добавить пользоватля в файл
htpasswd /путь/до/файла/с/паролями user_name
```
После ввода команды требуется ввести пароль пользователя. Все пароли в файле хранятся в зашифрованном виде.

### Настройка аутентификации

Для настройки аутнетификации используются следующие директивы (понятно, что они могут использоваться для настройки аутентификации в таких местах как `<Directory>`, `<FilesMatch>`, `.htaccess` и т.д.):
```
# Влючение базовой аутентификации
AuthType Basic
# Название аутентификации (будет высвечиваться в браузере)
AuthName "Restricted Area"
# Указание файла с пользователями
AuthUserFile /путь/до/файла/с/паролями
```

После этого, обретают смысл директивы `Reqire valid-user` и `Require user <конкретный>` (см. [[Главный файл конфигурации Apache]]).

### Настройка групп пользователей

Для этого надо влкючить модуль `authz_groupfile` как обычно командой `a2enmod`.
После этого появляется возможность задания групп через файл простого вида:
```
group1: user1 user2 ...
group2: user7 user3 ...
...
```
Чтобы этот файл учитывался при аутентификации его надо прикрепить:
```
AuthGroupFile /путь/до/файла/с/группами
```
И теперь появляется возможно добавлять доступ целой группе:
```
Require group group2
```

### Контейнеры RequireAny и RequireAll

Позволяют настраивать сложные правила доступа Require. 
Проще показать на примере:
```
# Доступ открыт либо администраторам, либо из локальной подсети
<RequireAny>
	<RequireAll>
		Require valid-user
		Require group admins
	</RequireAll>
	<RequireAll>
		Require ip 192.168.1.0/24
	</RequireAll>
</RequireAny>
```
Короче в контейнерах `<RequireAll>` мы перечисляем все условия, которые мы хотим чтобы выполнялись одновременно, а в `<RequireAny>` чтобы выполнялось хотя бы одно. Более того их можно комбенировать создавая сложные схемы
