
Настройка [[Принципы работы протокола SSL|SSL/TLS]] в Apache осуществляется через модуль **`mod_ssl`**. Его перед этим надо [[Модульная архитектура Apache|запустить]].

Директива `SSLEngine On` прописывается в контейнере [[Виртуальные хосты Apache|виртуального хоста]], в котором мы хотим настроить HTTPS протокол.
В директиве `SSLCertificateFile` указывается путь до сертификата, в `SSLCertificateKeyFile` путь до приватного ключа.

Можно указать и более продвинутые настройки:
* `SSLProtocol` - Разрешенные версии протоколов. Пример `SSLProtocol all -SSLv3 -TLSv1 -TLSv1.1`.
* `SSLCipherSuite` - Список разрешенных алгоритмов шифрования. Название алгоритмов прописываются слитно через  символ `-`.
* `SSLHonorCipherOrder on` - Заставляет сервер выбирать шифр из своего списка, а не клиента.

### Настройка HSTS

Для работы [[Механизм HSTS|механизма HSTS]] (что желательно для всех сайтов), необходимо добавить заголовок:
```
Header always set Strict-Transport-Security "max-age=31536000; includeSubDomains"
```
