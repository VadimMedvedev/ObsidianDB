
Обычно, Apache просто отдаёт файл при запросе GET, но иногда нам хочется другого поведения. Например иногда мы хотим генерировать веб страницы динамически используя скрипты на php, python и т.д. Тогда сервера должен сначала пропустить такой файл через интепритатор (обработчик, **handler**), а потом отдать пользователю. Именно настройкой обработчиков занимаются директивы `AddHandler` и `SetHandler`. 

Вот их отличия:

| Директива        | Что делает                                                                                                       | Пример                                                                         |
| ---------------- | ---------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| **`AddHandler`** | Связывает **расширение** с **обработчиком**. Работает только если расширение совпадает.                          | `AddHandler application/x-httpd-php .php`                                      |
| **`SetHandler`** | **Принудительно** назначает обработчик для **всех файлов** в текущем контексте, игнорируя расширения.            | `SetHandler application/x-httpd-php` (внутри `<FilesMatch>` или `<Directory>`) |

Возможные параметры (выбор обработчика):

| Значение                      | Модуль           | Описание                                                                                |
| ----------------------------- | ---------------- | --------------------------------------------------------------------------------------- |
| **`application/x-httpd-php`** | `mod_php`        | Стандартный обработчик для встроенного PHP.                                             |
| **`proxy:fcgi://...`**        | `mod_proxy_fcgi` | Отправка запроса на PHP-FPM (через сокет или TCP).                                      |
| **`cgi-script`**              | `mod_cgi`        | Обработка как CGI-скрипта.                                                              |
| **`default-handler`**         | `core`           | Сброс к обработчику по умолчанию (отдача файла как есть).                               |
| **`none`**                    | `core`           | Отключение любого обработчика.                                                          |
| **`server-info`**             | `mod_info`       | Страница информации о сервере. Т.е. заместо какого либо файла отправляется инфа о сайте |
| **`server-status`**           | `mod_status`     | Страница статуса сервера.                                                               |
| **`send-as-is`**              | `mod_asis`       | Отправка файла без заголовков HTTP (как есть).                                          |
