
Для запуска этого модуля, как [[Модульная архитектура Apache|обычно]], необходимо написать команду:
``` bash
a2enmod headers
```
После чего, чтобы он начал работать, надо перезапустить Apache.

Этот модуль позволяет настраивать заголовки ответов сервера.
Главная его директива `Header` имеет несолько опций:
```
Header add <заголовок> <значение> # добавить новый заголовок
Header set <заголовок> <значение> # установить заголовок
Header append <заголовок> <значение> # добавить если отсутствует
Header unset <заголовок> # удалить заголовок
```
Принципиальные отличия:
* `add` - добавит новый заголовок, даже если такой уже есть - то будет несколько. Полезно для повторяющихся заголовков по типу `Set-Cookie` или `Cache-Control`.
* `set` - устанавливает новый заголовок, если такой уже существовал, то перезаписывает. Используется для заголовков, которые не повторяются.
* `append` - добавляет новое значение в список значений заголовка через запятую. Полезно для заголовков, которые хранят списки.
* `unset` - удаляет если есть, и не жалуется если нет.

### Область применения заголовка

Но к каким именно запросам будет добавляться заголовок? Это зависит от места объявления его.
Можно использовать во всех основных контейнерах:
* В `apache2.conf` - будет прикрепляться ко всем ответам
* В `<VirtualHost>` - будет прикрепляться только к ответам этого сайта
* В `.htaccess` - к данной директории
* В `<Directory>` - к этой и всех вложенных директориях (расположенных физически)
* В `<Location>` - к виртуальной директории и всем вложенным
* В `<Files>`  и `<FilesMatch>` - ко всем подходящим файлам

### Опции onsuccess, always и early

Эти параметры можно указывать на третем месте:
```
Header add [onsuccess|always|early] <header> <value>
```
По умолчанию стоит `onsuccess`.
Значение этих параметров:
* `onsuccess` - этот заголовок будет прикрепляться в конце только при успешной обработке запроса сервером.
* `always` - этот заголовок будет включаться всегда на финальном этапе отправки
* `early` - записывается сразу после получения запроса, и может быть изменён/удалён/перезаписан скриптом или ещё чем-то

### Настройка CORS

Так как [[Механизм CORS|CORS]] работает исключительно на заголовках, то настройка CORS в Apache заключается только в добавлении заголовков к ответам на разные ресурсы, используя модуль headers.
