
**Модули Apache** - это компоненты, которые расширяют функциональность веб-сервера Apache HTTP Server. Они позволяют добавлять новые возможности без изменения основного кода сервера.

Таким образом, вся архитектура Apache как бы складывается из модулей.

Все **работающие** модули можно посмотреть командой:
``` bash
apache2ctl -M
```

Следующие команды являються основными для работы с модулями:
``` bash
a2enmod rewrite # включить модуль rewrite
a2dismod rewrite # выключить модуль rewrite
```
Для того чтобы модули начали работать, весь apache нужно перезапустить:
```
Systemctl reload apache2
```
