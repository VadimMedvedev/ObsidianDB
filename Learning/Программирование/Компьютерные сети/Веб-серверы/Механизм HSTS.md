
**HSTS** — это механизм безопасности, который заставляет браузеры использовать **только HTTPS** для соединения с сайтом, игнорируя любые попытки перейти на HTTP.

Это **HTTP-заголовок**, который сервер отправляет браузеру. После получения этого заголовка браузер запоминает правило и в будущем автоматически конвертирует все HTTP-запросы в HTTPS, даже если пользователь ввел `http://` в адресной строке или кликнул на HTTP-ссылку.

Синтаксис заголовка:
```
Strict-Transport-Security: <параметры, мб нескольк через ';'>
```

Основные параметры:

| Параметры               | Описание                                                               | Обязательность  |
| ----------------------- | ---------------------------------------------------------------------- | --------------- |
| **`max-age=<секунды>`** | Время (в секундах), в течение которого браузер должен помнить правило. | **Обязательно** |
| **`includeSubDomains`** | Правило распространяется на все поддомены.                             | Опционально     |
