
В Apache можно настроить работу несольких сайтов одновременно. Каждый отдельный сайт называется виртуальным хостом и определяется через контейнер `VirtualHost`, в котором прописываються его особые настройки.

Они обычно указываются отдельно в файлах в директории `sites-available`. В один файл стоит объединять виртуальные хосты с одним доменным именем (если конечно же имеется).

### Выбор виртуального хоста из нескольких

Алгоритм выбора:
1) Apache смотрит: запрос пришел на IP:порт (можно прослушивать несколько портов, как и у сервера может быть несколь IP адресов):
	* В наилучшем случае использует `<VirtualHost IP:порт>`
	* Если нет, использует `<VirtualHost *:порт>`
2) Есть несколько хостов на одном IP:порту, то смотрит на заголовок `Host`, т.е. на какое доменное имя было отправлено:
	* Ищет подходящие сайты по ServerName и ServerAlias
	* Если не находит, использует первый по списку

Таким образом видно, что идентифицируют каждый сервер адрес, порт (указанные в настройке контейнера) и доменное имя (Указанное либо в `ServerName`, либо в `ServerAlias`).

Основное отличие `ServerAlias` от `ServerName` в том, что в ошибках будет указываться именно `ServerName`, т.е. виртуальный хост будет идентифицировать себя именно по этому имени.

### Настройки виртуальных хостов

**В Apache правит наследование!** Поэтому ранее определённые параметры в файле `apache2.conf` распространяюстя и на все виртуальные хосты.
Но мы можем переопределять, прописывая [[Главный файл конфигурации Apache|теже параметры]] в каждом контейнере хоста по отдельности.
Примеры таких переобозначений:
`ServerName` - определяет доменное имя для каждого хоста в отдельности (чтобы вообще их можно было отличить)
`DocumentRoot` - откуда начинается корневой католог конкретного сайта
`ServerAdmin` - email конрктного администратора, отвечающего именно за этот сайт
`ErrorLog`- особый файл для ведения логов этого сайта
`<Directory>` - настройка особых правил директорий именно с этого сайта
