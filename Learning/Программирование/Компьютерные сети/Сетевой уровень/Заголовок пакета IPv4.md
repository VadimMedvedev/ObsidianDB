
Эти заголовки используються чисто службами третьего уровня для маршрутизации пакетов. До уровней выше приходят уже деинкапсулированные данные, а нижние его не читают.

1) Версия - либо 4, либо 6. Для них свои 4 битные коды
2) Размер заголовка
3) Дифференцированные сервисы (DS) - служит для определения приоритета этого пакета в сети.
4) Общий размер всего пакета
5) Флаги
6) TTL - время жизни - т.е. время сколько пакет будет гулять по маршрутизаторам. Каждый раз когда пакет приходит на маршрутизатор, он уменьшает его на один. Если оно уменьшается до нуля, маршрутизатор выкидывает его.
7) Протокол - используется для определения протокола следующего уровня
