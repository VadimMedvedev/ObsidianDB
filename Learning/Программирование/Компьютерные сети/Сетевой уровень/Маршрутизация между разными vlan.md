
Сами коммутаторы не могут перенаправить трафик из одного [[VLAN сети|vlan]] в другой. Другими словами, отправляя пакет с ip устройства из нашей локальной сети, но в разных vlan, оно не дойдёт до получателя, как если бы они были в разных локальных сетях. Оно просто не достежимо на уровне L2. Значит для перенаправки между vlan надо использовать более умные устройства, такие как маршрутизаторы.

### Устаревший метод маршрутизации между VLAN

Раньше между коммутаторам и маршрутизаторам прокладывалось несколько кабелей, по количеству используемых vlan. Таким образом каждой vlan соответсвовала своя подсеть. Тогда нужно было и устройствам давать ip адреса соответсвующих подсетей, а не одной в которой они физически все были подключены.
Таким образом пакеты, предназначенные для устройства из другого VLAN предназначались другой сети и автоматически пересылались на маршрутизатор, который отправлял их на интерфейс связанный с портом коммутатора окрашенный в этот vlan.

### Метод Router-on-a-Stick

В этом способе используется только один интерфейс маршрутизатора.

В таком способе один из интерфейсов маршрутизатора настраивается в качестве магистрального порта для распознования тегов. Для каждой VLAN создаётся логические (виртуальные) подчинёный интерфейсы. Для каждого подчинённого интерфейчас настраивается свой VLAN и ip адрес.
Таким образом мы как бы создаём транк сежду комутатором и маршрутизатором. Но в силу того что маршрутизатор L3 устройства он перенаправляет трафик с одного на другой свой подчинёный виртуальный интерфейс.

### Используя протокол SVI

Маршрутизировать пакеты можно и на коммутаторах L3. Для этого создан протокол SVI (switch virtual interface). 
По сути этот коммутатор L3 становиться шлюзом для всех vlan.

На коммутаторе L3 можно для каждого vlan задать свой ip адрес. Тем самым свитч L3 получает виртуальные интерфейсы торчащие в виртуальные сети vlan. Все устройства в качестве шлюза по умолчанию используют адрес его интерфейса в данной vlan.
