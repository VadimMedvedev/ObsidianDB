
Каждый раз когда он получает пакет, он смотрит что с ним делать смотря в свою таблицу маршрутизации.
У каждого маршрута по сути есть несколько видов маршрутов:
1) Маршруты с прямым подключением. По сути это локальные сети, в которых у маршрутизатора торчит один из интерфейсов.
2) Удалённые маршруты. Например если R1 и R2 маршрутизаторы подключены к одной локальной сети, то маршрутизатор R1 знает что может достучаться до локальных сетей R2 через их общую локальную сеть. Таким образом он отправляет все пакеты до удалённых хостов в эту общую локальную сеть. Эти маршруты и называються удалёнными
3) Маршрут по умолчанию. Используеться когда маршрутизатор не знает куда отправлять пакет, у него нет записи об этой локальной сети. Если не указан, то маршрутизатор будет отбрасывать все пакеты, которые не знает куда отправить.

Прямые подключения записываються следующим способом:
Для каждого активированного интерфейса маршрутизатор автоматически создаёт две записи:
1) Одна начинается с буквы C и указывает что интерфейс подключен напрямую к этой сети, он включен и ip настроен.
2) L это локальный интерфейс, т.е. просто адрес интерфейса для этой сети

Удалённые маршруты записываються так, в нём следующие поля:
1) D обозначает каким обращом маршрутизатор получил информацию об этой сети. Именно буква D обозначает что использовался протокол EIGRP.
2) Затем идёт сеть в которую идёт маршрут
3) Затем расстояние до этой сети. Например: 90
4) Метрика, т.е. значение для достижения маршрута. Чем оно меньше, тем предпочтительнее маршрут
5) Адрес маршрутизатора к которому надо переслать пакет. По хорошему этот адрес должен лежать в сети, к которой этот маршрутизатор подключен напрямую.
6) метка времени, когда в последний раз этим маршрутом пользовались

Тут важно, что если такой сетки нет в таблице у маршрутизатора, то он отбросит пакет. Но можно настроить маршрут по умолчанию, чтобы пакеты не убивались, а отправлялись на этот интерфейс.
Маршрут может быть одно сторонним, т.е. обратный путь второй маршрутизатор может и не знать.
Путь в одну сторону может быть не равен путю обратно.
