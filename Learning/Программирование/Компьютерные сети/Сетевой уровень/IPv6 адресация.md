
Усовершенствования:
* 128 бит под адрес. Это 340 ундециллионов адресов, хватит каждой пещинке на земле.
* Устраняет многие ограничения IPv4.
* Такие усовершенствования как: автоматическая натройка адреса.

Вообще плохо работает если одновременно использовать два адреса IPv4 и IPv6.

### Запись адреса IPv6

128 бит делятся на 8 гекстетов (кусочки по 16 бит) разделённые двоеточием. каждые 4 бита записываються 16 рично1 цифрой.
##### Правила записи:
* Все последние нули в каждом гекстете не пишутся.
Пример:
полный: 2001:0db8:0000:0000:0000:ff00:0042:8329
сокращённый: 2001:db8:0:0:0:ff00:42:8329
* Пропуск нескольких нулевых сегментов, заместо них ставиться два двоеточия подряд. Но так можно сократить один адрес только один раз (иначе будет не понятно сколько гексетов мы сокращаем каждый раз).
Пример:
полный: 2001:0db8:0000:0000:0000:ff00:0042:8329
сокращённый: 2001:db8::ff00:42:8329
Адрес с нулями в каждо гексете записывается просто: ::

### Типы адресов

**Индивидуальный** IPv6 адрес источника.
**Групповой**, используемый для отправки пакетов сразу нескольким устройствам.
Бродкастный адрес убрали, но теперь за место него есть особый мультикастный адрес.
**Произвольный** адрес (anycast) - адрес, выглядищий как обычный юникастный, но приписан нескольким узлам. Тогда при адресации на такой адрес, пакет доставиться произвольному узлу имеющему такой адрес. Для такой рассылки необходима специальная конфигурация узлов имеющих такой произвольный адрес.

Бродкаста теперь нет.
Без бродкаста теперь не получается использовать ARP запросы. Теперь для этого используется другой протокол (ICMP).

среди индивидуальных адресов выделяют следующие виды:
1) Локальный индивидуальный адрес канала (link-local) это адреса в диапозоне FE80:: /10. Он нужен всегда для работы системы с IPv6. Он создаёться даже когда нет глобального инивидуального адреса. Его используют разные сетевые службы, а также шлюз по умолчанию обычно записывается этим адресом.
2) Глобальные индивидуальные адреса - белые адреса для хостов. Уникальные во всём мире, они используються для маршрутизации через интернет.
3) Уникальные локальные адреса - используються для адресации в пределе одной локальной сети. FD00:: /8
Таким образом один интерфейс может иметь сразу несколько разных адресов для разных нужд.

Пока что назначаються IPv6 глобальные адреса начинающиеся с первых 3 битов 001, т.е. в диапозоне 2000::/3.
Они состоят обычно из трёх частей:
1) Префикс глобальной маршрутизации. Это часть назначаемая провайдером, обычно это первые 48 бит.
2) Идентификатор подсети, обычно оставшиеся 16 бит
3) Идентификатор интерфейса. Т.е. уже уникальная часть характерезующая интерфейс в подсети.

Но всё же есть аналог бродкаста, называется присвоенные груповые адреса:
1) FF02::1 - ссылается на все устройства в локальной сети использующие ipv6. Полный аналог 255.255.255.255.
2) FF02::2 - рассылка всем маршрутизаторам работающие с IPv6.

### Ещё про link-local адреса

Они обычно генерируються так (процесс EUI-64):
1) в первых 64 битах идёт FE80:0:0:0
2) В хостовую часть помещается mac адрес, по середине которого вставляют ff:fe и 7 бит инвертируют
Пример:
MAC: `00:15:5D:A8:3C:2E`
Pv6 Link-Local: `FE80::215:5DFF:FEA8:3C2E`
Но можно их настраивать и случайным образом и вручную.

Пакеты с link-local адресом никогда не покидают lan, они распространяються только в его пределах.
Они обязательно создаються для каждого устройства использующего IPv6.

### Способы конфигурации IPv6 адреса

Можно настроить статически: процес такой же как и при настройки IPv4. Он происходит также на всех ОС и на сетевых устройствах. В качестве шлюза по умолчанию можно написать как его глобаный индивидуальный адрес, так и локальный.

Динамически задать адрес можно двумя способами:
##### SLAAC
Устройство может получить префикс, длину префикса и адрес шлюза по умолчанию и дргуие сведенья от маршрутизатора через протокол ICMPv6. Такие сообщения отправляються каждые 200 секунд всем устройством сети от маршрутизатора. Такие сообзения называються RA (router advertisement)
Запрос к маршрутизатору по ICMPv6 называется RS (router solicitation).

##### DHCPv6
DHCP сервера тоже могут использоваться для конфигурации адреса.  Из них можно получать более полную информацию о сети и создавать статические адреса.

Можно использовать только SLAAC, только DHCPv6, или их обоих вместе.



### Префикс

Обычная длина сетевой части в ipv6 занимает 64 по умолчанию. Но конечно может варьироваться от 0 до 128. Длина префикса также записывается через / после самого адреса.
