
Все виртуальные машины создаваемые в libvirt подключаються к виртуальному коммутатору. По умолчанию он называется virbr0. Хостовая машина к нему тоже "подключена". На ней можно увидеть подключённый к этому свечу интерфейс, по умолчанию, с ip адресом 192.168.122.1.

### Режимы работы виртуального коммутатора

##### NAT
По умолчанию коммутатор работает в режиме NAT. Т.е. он создаёт подсеть со своими внутренними ip адресами. Каждая внутренняя машина тогда сможет получить доступ к внешней (т.е. находящейся не в этой виртуальной сети), но внешние машины не будут видеть эти внутренние машины сидящие за NAT.

##### Routed mode
В этом случае трафик из внутренней и внешней сети ходит свободно в обе стороны. Создаёться подсеть в изначальной физической сети, в которой находитсья хостосвая машина. Но внешние машины всё равно не могут увидеть эти машины, поэтому требуется настройка static route, чтобы они смогли связаться с виртуальными машинами.

##### Isolated mode
Виртуальные машины могут общаться только между собой и хостом. Связь из внешней локальной сети к ним или наоборот работать не будет.

### Работа DNS и DHCP

Каждому коммутатору в виртуальной сети можно выдать диапозон адресов, которые можно выдавать через DHCP. Для этого libvirt использует утилиту dnsmasq. libvirt автоматически создаёт экземпляр ndsmasq для нуждающегося коммутатора.

### Коммутатор по умолчанию

Изначально настроена default сеть, в которой коммутатор стоит в режиме NAT и на нём установлены DNS и DHCP сервера. ip адреса в его подсети имеют вид: 192.168.122.12. Он носит название virbr0.
