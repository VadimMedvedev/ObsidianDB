
Информация ОС может храниться в [[Способы хранения дисков QEMU|разных форматах]], для того чтобы настраивать это используются команды qemu.

qemu-img - обащая утилита для работы с образами дисков
1) convert -f <формат 1> -O <формат 2> <файл 1> <файл 2> - конвертирует файл 1 образа диска из формата 1 в формат 2 и сохраняет его как файл 2.
2) create -f <формат> <файл> <размер> - создаёт файл образ диска с указанным форматом нужного размер (например 10 G). Сохраняет его как <файл>.
3) info <файл> - выводит краткую информацию об образе диска.
