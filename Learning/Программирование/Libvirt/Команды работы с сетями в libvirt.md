
Все команды запускаються либо в интерактивной среде virsh, либо из CLI, как составная команда `virsh <command>`.
* `net-list [--all]` - выводит работающие сети, с ключом all выведет все.
* `net-start <network>` - включает сеть
* `net-destroy <network>` - выключает сеть
* `net-undefine <network>` - полностьб удаляет сеть
* `net-autostart <network> [--disable]` - ставит сеть на автозапуск (будет автоматически включаться при запуске хоста). С ключом disable снимает с автозапуска.
* `net-dumpxml <network>` - показывает конфигурацию сети в формате XML.
* `net-define <XML файл>` - добавляет новую подсеть описанную в XML файле.
* `net-edit <network>` - позволяет изменить сеть через формат XML.
