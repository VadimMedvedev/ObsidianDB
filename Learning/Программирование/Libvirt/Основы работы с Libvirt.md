
Можно посмотреть все поддерживаем технологии libvirt:
``` bash
virsh -V
```
Все гипервизоры, способы хранения данных, сетевые технологии.

Чтобы зайти в libvirt пишем команду virsh (надо находиться в primary группе libvirt). Откроется внутренний интерфейс со своими командами. Такой формат совсем не удобен для виртуализации
Более того, можно использовать libvirt не заходя во внутреннее окружение virsh, а используя команды так:
``` bash
virsh command
```

libvirt использует файлы в формату xml для хранения данных, конфигов. Он похож на HTML, но если у HTML теги строго установленные, специальные для отображения данных на странице, то у XML они могут быть произвольными, такие какие нужны для передачи данных.

libvirt поддерживает мультипользовательский режим, т.е. в зависимости от того, под каким юзером ты заходишь, будут показываться ВМ только этого юзера.
