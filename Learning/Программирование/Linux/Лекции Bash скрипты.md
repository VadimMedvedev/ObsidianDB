diff - построчное сравнивает два файла
grep - выводит строчки, которые подходят под регулярные выражения (чтобы сделать поиск по нескольким регулярный выражением перед каждым из них пишем -e, выводиться будут строчки подходящие хотя бы по одному из выражений)
* "\\<text" - выводит все строчки начинающиеся с text
* "text\\>" - аналогично но в конце

* %x - переводит число в 16 ричную систему счисления (%X печатает буквы большими)
* %d - 16 -> 10

* -b - все 16 числа записываются в 10 системе по две штуки (0 до 255)
* -с - каждая ячейка - символ, можно увидеть отдельно по символу

1) -d - истинна если существует и это каталог
2) -e - истинна если файл сущестует
3) -f - истеннна если являеться обычным файлом
4) -r доступен для чтения
5) -w доступен для записи
Оператор ~= сравнивает слово с регулярным выражением. В одинарных квадратных скобках нельзя работать с регулярными выражениями, надо использовать \[\[\]\]. Если поставить регулярные выражения в кавычки, то это будет просто строка.
read - считывает из консоли и помещает в аргумент (переменная). -p что выведеться, приглашение к вводу
pgrep <процесс> - проверяет рабоает ли процесс
alias <название>="команда с ключами" - в данном сеансе теперь можно обращаться к этой большой команде как <название>. В .bashrc. можно записать постоянные всевдонимы.
eval "str" - запускает текст как команду и возвращает результат. 
seq - последовательность создаёт
sleep - засыпает на некоторое время указываем число и суфикс: s, m, h, d

### Скрипты

Это автоматизация - это круто!

Шебанг
``` bash
#!/bin/bash
```
показывает как запускать этот скрип, при помощи чего.
После шебанга пишем сам скрипт, последовательность команд bash.
После # идут комментарии.

При передаче аргументов вместе с командой к ним можно обратиться через $1, $2 и т.д., $# - сколько аргументов всего введено, $@ - список всех аргументов

В $? записываеться код ошибки. Стандартные:
* 0 - всё отлично
* 1 - общая ошибка
* 127 - не найдена команда
* 128 - неверный аргумент

### Ветвление

if - основное словие
elif - другое условие, но не совсем else
else - иначе
fi - конец ветвеления

``` Bash
if [ $number -gt 100 ];
then
	echo 'число больше 100';
else
	echo 'меньше 100'
fi
```

Важный пример для проверки входных параметров:
``` bash
if [ -z "$1" ];
then echo "Нет параметров"
fi
```

### case

``` bash
case <сравнимое значени> in
	<маска 1>) <команды> ;;
	<маска 2>) <команды> ;;
	...
esac
```
Маска \*) используеться для варианта по умолчанию (если никакой другой не выбран). Можно перечислить несколько разных вариантов для одного отдельного кейса так <маска 1>|<маска 2>|...|<маска n>.
В качестве масок можно использовать регулярные выражения.
Если после ;; стоит &, т.е. ;;&, то после того как этот блок отработает, он продолжит проверку, т.е. может выполниться несколько кейсов.

### Циклы

``` bash
for var in list
do
	echo "Значение $var"
done
```
в качестве list можно поставить например $(ls \*.txt).
IFS - переменная среды которая 

Цикл со счётчиком:
``` bash
for ((i=10;i>=1;i--))
do
	echo "Значение счётчика $i"
done
```

Команда break прерывает цикл. Прервать итерацию и перейти на следующий шаг continue.

Цикл while работает аналогично как и везде, но только с условием.
Двойные каычки \[\] не воспринимают регулярные выражения, поэтому стоит использовать \[\[]], когда использються wildcard.

until - то же что и while но пока условие не будет выполнено.

### Массивы

Есть только одномерные.
Объявление массива, два способа:
``` bash
declare -a mas
mas=( item1 item2 ... itemn )
```
В массиве можно хранить элементы разных типов.
${array\[\@\]} выводит всех художников.
