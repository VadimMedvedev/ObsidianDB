
Остановленный процесс помечается [[Состояния процессов|статусом]] T и лежит в [[Процессы в Linux|фоновом режиме]].

Вызвать остановку процесса можно, например, сочетанием клавиш ctrl + Z в процессе выполнения программы. Она сразу после этого переходит в фоновый режим.

Если в системе есть остановленные процессы, то команда exit не позволит выйти из учётной записи, для начала надо будет остановить все фоновые процессы. 
Если ввести exit два раза подряд, то система завершит все остановленные процессы и выйдет.
