
Снепшот (snapshot) LVM — это моментальный снимок логического тома, фиксирующий его состояние на определенный момент времени. Он работает по принципу Copy-on-Write (CoW): при создании снапшота данные не копируются полностью, а в него записываются только те блоки данных, которые изменяются на оригинальном томе.
Например если было 4 блока данных: A, B, C и D, и блок B изменили на B* то станет:
```
origin:
[A][B*][C][D]

snapshot:
   [B]
```
Т.е. в снепшот записывается то, изменилось, старый вариант.

Создание снепшота. на основании какого-то LV. Тут важным является ключ `-s` именно он отвечает за создание cнепшота.
``` bash
lvcreate -L 1G -s -n snap1 /dev/vg_data/lv_data
```

Теперь у нас есть два основных пути:
1) Мы можем понять, что нам больше не нужно хранить старое состояние LV, оно нам не нужно, то мы просто удаляем снепшот:  `lvremove snap1`.
2) Мы хотим откатится к снепшоту, то тогда мы должны все старые версии блоков данных обратно вернуть в ориджин, объединить их, это делается командой `lvconvert --merge snap1`. Изменения придут в силу после перезагрузки.

### Важный нюанс

Когда снепшот полностью заполняется, то он становится не действительным (INVALID), к нему нельзя будет больше обратится. Поэтому надо вовремя либо его расширять (`lvextend`) или же удалять и создавать новый.
Также можно автоматизировать расширение снепшота, это делается через конфиг LVM. В файле `/etc/lvm/lvm.conf` надо добавить:
```
snapshot_autoextend_threshold = 70 # при превышении какого процента объёма надо добавлять размер
snapshot_autoextend_percent = 20 # насколько процентов от оригинального объёма увеличивать
```
Например, если максимальный размер снапшота — 1 Гб, и его заполненость стала больше 700 Мб, то он расширится до 1.2 Гб.
