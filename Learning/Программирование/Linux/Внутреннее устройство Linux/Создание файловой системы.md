
Создание файловой системы на разделе (см. [[fdisk, cfdisk и sfdisk|управление разделами]]) происходит очень просто. Для каждой файловой системы есть своя утилита для создания, они называются единообразно `mkfs.*`.
Таким образом чтобы на разделе поставить файловую систему надо написать:
```
mkfs.ext4 /dev/vda1 # путь до файла-раздела
```

Более того, можно поставить ФС на весь диск. Тогда всякие [[Таблицы разделов|таблицы разделов]] снесутся, и весь диск будет по сути одной большой ФС. Его можно будет примонтировать как обычный раздел.
Диск типа перестаёт контролироваться таблицей разделов, которая выделяет отдельные разделы где правят ФС, теперь весь диск управляется ФС. Из-за этого некоторые утилиты работающие с таблицей разделов не будут воспринимать вообще этот диск (например fdisk).
