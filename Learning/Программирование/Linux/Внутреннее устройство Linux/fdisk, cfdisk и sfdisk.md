
fdisk, cfdisk и sfdisk - это три основные утилиты которые позволяют работать с таблицами разделов.

### fdisk

Утилита для ручной настройки через терминал.
Для входа в её интерфейс набираем:
```
fdisk /dev/vda # указываем наш диск
```
Нажав `m` можно посмотреть все основные команды, их не так много.
Основные сценарии использования:
* `g`/`o` - создать абсолютно новую таблицу с GPT/MBR. Здесь Dos=MBR.
* `q`/`w` - выйти и выйти с сохранением
* `p` - вывод таблица разделов, можно посмотреть все разделы, их объём, тип, и тип самой таблицы разделов (MBR/GPT).
* `n` - создать новый раздел
* `d` - удалить один из разделов.

### cfdisk

Является TUI версией fdisk. Удобно.

### sfdisk

Делает процесс разметки диска автоматизируемым.

Самый простой пример:
``` bash
sfdisk -d /dev/vdb > layout.txt # дамп структуры диска vdb
sfdisk /dev/vdb < layout.txt # загрузка структуры диска на файл
```

Но sfdisk имеет конечно больший функционал.
