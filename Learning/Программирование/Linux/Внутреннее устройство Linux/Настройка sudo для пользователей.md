
Команда sudo (substitute user do) позволяет пользователям выполнять команды от лица других пользователей.

### Принцип работы

Это работает так. Пользователь пишет команду типа `sudo command ...`, тогда утилита смотрит в файл `/etc/sudoers` в котором прописаны правила использование этой команды. В базовой конфигурации:
```
root	ALL=(ALL) 	ALL
%sudo	ALL=(ALL)	ALL
```
Каждая запись в этом файле это:
* Пользователь (`username`) или целая группа (`%groupname`)
* с какого хоста (`ALL` - с любого, `localhost` - только с этого)
* вместо какого пользователя (вместо всех `ALL`, или конкретных)
* Что можно выполнять (всё `ALL` или только ограниченный набор команд)

Таким образом root пользователю можно выполнять команды от любого лица и пользователям в группе sudo можно также.
Так что самый простой способ дать возможность использовать sudo пользователю, это добавить его в группу sudo.

### Подробнее о команде sudo

Выполнение команды за конкретного пользователя:
```
sudo -u postgres
```

Важно, когда мы заходим по ssh, то нам может быть запрешён доступ, если указано только `localhost`.
Т.е. мы с компьютера А заходим на компьютер Б по ssh, и там используем sudo. В таком случае, если прописано `localhost` нам откажут в доступе.

### Подробнее о файле sudoers

Указание возможных подстановок в скобках необязательно, как и возможно добавление также разрешённых групп через `:`. Т.е. возможны следующие записи:
```
vadim	ALL=(ALL:ALL) 	ALL
liza    ALL=ALL
```
В первом случае, если ты пытаешься войти за пользователя который не перечислен, то проверится, возможно ты заходишь за пользователя разрешённой группы, и тогда тебя всё равно пустят.
Во втором случае можно заходить за любых пользователей.

Примеры:
```
vadim ALL=(root) ALL # можно заходить только за root

vadim ALL=/sbin/reboot # только reboot
vadim ALL=/sbin/reboot, /sbin/shutdown # несколько команд
vadim ALL=/usr/bin/systemctl restart nginx # эта команда только с этими аргументами
```

Можно создавать псевдонимы сразу на несколько объектов:
```
User_Alias ADMINS = alice, bob, vadim # пользователи
Runas_Alias DBUSERS = postgres, mysql # от кого исполнять
Host_Alias SERVERS = server1, server2
Cmnd_Alias WEB = /bin/systemctl restart nginx, /bin/systemctl reload nginx
```

Для некоторых команд можно прописывать отдельные модификаторы:
```
vadim ALL=(ALL) NOPASSWD: ALL # разрешено делать всё без ввода пароля
```

Можно через запятую и `!` прописывать исключения, что нельзя:
```
Cmnd_Alias SAFE = ALL, !/bin/su, !/bin/bash
```
