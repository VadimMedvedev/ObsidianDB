
### Файл  /etc/group

Все группы можно посмотреть в файле /etc/group. В этом файле каждая строчка имеет вид:
```
group_name:x:gid:user1,user2
```
У каждой группы, также как и у каждого пользователя, есть свой номер в системе gid (group ID).
Также в этом файле хранится информацию о пользователях, которые принадлежат той или иной группе.

### Первичная и вторичная группа

Первичная группа (primary group) — это основная группа пользователя, которой по умолчанию присваиваются права доступа к создаваемым им файлам, и имя которой обычно совпадает с именем пользователя; 
Каждый пользователь имеет ровно одну первичную группу, в отличие от вторичных (дополнительных), к которым он может быть приписан для получения расширенных прав. 
Первичная группа всегда создаётся при создании пользователя, но [[Команды работы с группами|может быть изменена]].
