
Один компьютер могут использоватль несколько человек, поэтому в Linux можно создать нескольких пользователей на человека. Помимо того, в системе уже есть некоторые системные (виртуальные) пользователи, которые используються для работы системы.
Но ОС работает с ними через uid (user ID), личный уникальный идентификатор. Изначально в системе root имеет номер 0, пользователь bin номер 2, а все создаваемые нами пользователи получают номера от 1000 и т.д.

Всех пользователей можно посмотреть в файле /etc/passwd. Разберём основные столбцы в этом файле напримере:
```
vadim:x:1000:1000::/home/vadim:/bin/fish
```
1) Имя пользователя
2) x стоит у всех пользователей во втором столбце. Раньше в этот столбец записывали зашифрованный пароль пользователя, но сейчас решили что это небезопасно и пароли хранят в другом месте (/etc/shadow), а здесь стоит x.
3) uid пользователя
4) ?
5) Описание пользователя
6) Домашняя директория пользователя
7) [[Shell|Shell]] который запускается при входе пользователя. У некоторых системных пользователей здесь написано /sbin/nologin - это заглушка, при попытке входа в этого пользователя, будет запускаться этот файл, который будет выбрасывать обратно.

В качестве shell можно поставить и любое другое приложение, например vim, но тогда пользователь кроме vim нигде не сможет работать, и при выходе из vim он будет выходить из учётный записи.
