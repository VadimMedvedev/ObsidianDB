
Это [[Избирательные права доступа DAC|дополнительные права и запреты]] которые можно накладывать на файлы в системе.



### Sticky bit

Этот атрибут в основном накладывается на директории. Если директория имеет Sticky bit, то каждый файл в ней может быть удалён только своим владельцем.

Если мы просто навешиваем права w и x на некоторую директорию для пользователей помимо владельца, то эти пользователи смогут как добавлять в файлы в неё, так и удалять (конечно редактирование файлов уже зависит от прав самого файла а не директории).
Но иногда появляется необходимость сделать "общий склад" для файлов для нескольких пользователей (например в системе это директория /temp), причём чтобы они не могли только складывать туда файлы и не могли удалять файлы друг друга. Тогда на помощь приходит sticky bit.

Поставить его можно при помощи [[Команды изменения прав доступа|команды chmod]].

Определить, что директория наделена sticky bit можно при помощи вывода [[Команды работы с файловой системой|команды ls -l]].
Пример: drwxrwxrwt, символ t символизирует наличие sticky bit на этой директории.
Заметим, что в записи используется t - когда [[Избирательные права доступа DAC|права исполнения для других пользователей]] есть и T когда их нет.
Таким образом в директорию drwxrwx--T смогут пдобавлять файлы только владелец и его первичная группа, а другие вообще не будут иметь доступ к этой директории.
