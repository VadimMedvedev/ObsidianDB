
Модули ядра — это динамически загружаемые компоненты Linux kernel, которые позволяют расширять функциональность системы без полной перезагрузки. По сути, это куски кода (обычно драйверы устройств, файловые системы, сетевые протоколы), которые можно «подгружать» и «выгружать» на лету.

Модуль — это объектный файл (`.ko` — kernel object), который:
- загружается в пространство ядра
- работает с теми же привилегиями, что и само ядро
- может взаимодействовать с оборудованием и другими частями системы
Они лежат в директории `/lib/modules/` (они там специальным образом рассортированы).

Чтобы модуль загружался при старте достаточно добавить его имя в файл: `/etc/modules`.

### Основные команды

##### `lsmod` — список загруженных модулей
Показывает, какие модули сейчас активны:
Вывод:
- имя модуля
- размер
- сколько раз используется (use count)

##### `modinfo <название>` — информация о модуле
Показывает:
- описание
- автора
- зависимости
- параметры

##### `modprobe` — умная загрузка/выгрузка
Есть конечно низкоуровневые утилиты `insmod` и `rmmod` но они не учитывают зависимости и т.д. Толку от них нет. `modprobe` автоматизирует всё необходимое
```
sudo modprobe [-r] имя_модуля
```
Ключ -r выгружает модуль
