
Для начала ознакомься с [[Система управления томами LVM|теорией]].

### Настройка физических дисков (PV)

```
pvcreate /dev/vda1 # создание PV из раздела/диска
pvs # краткий обзор всех PV
pvdisplay # детальная информация о всех PV
pvrevome /dev/vda1 # удалить
pvmove pv1 pv2 # перенести все данные с одного диска на другой
```

### Настройка групп томов (VG)

```
vgcreate vg_name pv1 pv2 ... # создание VG из нескольких PV
vgs # Краткий обзор
vgdisplay # подробный обзор
vgremove vg_name # удалить
vgextend vg_name pv_name # расширить группу
```

### Настройка логических томов (LV)

```
lvcreate -n имя -l размер VG_name # создание LV в VG
lvs # Краткий обзор
lvdisplay # подробный обзор
lvremove dev/vg/lv # удалить
lvextend -l размер /dev/vg/lv # необязательно увеличение размера, размер
# можно и уменьшить (хотя это не безопасно)
# для уменьшение на конкретное значение подписываем -, а для увеличения +
# например -L +10G или -l -300
```

После создания LV, к нему можно обращаться по пути `/dev/vg_name/lv_name`, и так надо делать каждый раз когда мы хотим использовать этот логический том. Т.е. при удалении, расширении, создании на нём ФС, монтировании и т.д.

Для задания размер дискового пространства (при создании или при увеличении) можно использовать два ключа:
* `-L` - абсолютный размер, т.е. указываем насколько конкретно создать lv. Например `-L 10G`, `-L 500M` или `-L 1T`.
* `-l` - в логических экстендах (LE). Указываем просто число логических экстендов для использования. Но также можно указывать и относительную величину в процентах, например: `80%FREE`. Всего есть несколько суффиксов:
	* `%VG` - процентов от всего объёма VG
	* `%FREE` - процентов от свободной части

Важно, что при увеличении размера LV, надо также увеличивать ФС на всё пространство LV (эта процедура различается между разных файловых систем).
