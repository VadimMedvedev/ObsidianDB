
Монтирование — это **привязка файловой системы к каталогу**. После этого всё содержимое диска видно внутри директории.
Но что тогда становится с файлами, которые было до этого в каталоге? Они на время скрываются.

Основные команды для этого `mount` и `umount`:
```bash
mount [ -o opt1,opt2,.. ] /dev/vdb1 /data # примонтировали раздел к директории data
umount /data # отмонтировали
umount /dev/vdb1 # такой же эфект, что и прошлое
```

### Опции

С ключом `-o` можно записывать несколько опций (через запятые без пробелов) которые определяют правила работы с файлами на этом томе.
* `ro` - только чтение
* `rw` - чтение и запись
* `noexec` - запрет на выполнение файлов
Перед следующей партией опций надо вспомнить, что у каждого файла есть временные метаданные `atime` - последнее чтение файла, `mtime` - последнее изменение файла, `ctime` - последнее изменение метаданных.
* `noatime` - не обновляет atime для файлов (может пригодится, когда происходит много чтения, и это постоянное обновление метаданных замедляет работу). Часто используется для баз данных.
* `nodiratime` - тоже самое но для директорий. Идут часто вместе с `noatime`.

### Файл /etc/fstab

Но все блочные устройства примонтированные командой `mount` сбросятся после перезагрузки. Для того чтобы они каждый раз монтировались в систему при загрузке, надо вписать их в файл `/etc/fstab`.
В нём каждая запись имеет следующий вид:
```
<device> <mountpoint> <fstype> <options> <dump> <pass>
```
В device указывается идентификатор блочного устройства, т.е. либо путь (типа `/dev/vda`), либо UUID устройства: `UUID=abcd-1234` (можно посмотреть через [[Команды для изучения блочных устройств|blkid]]).
В options указываются те же опции, что задаются при команде `mount`. Если никаких опций нет, то пишется просто `defaults`.
dump уже устарела и не используется, просто записывается всегда `0`. А в pass указывается fsck порядок (порядок проверки файловой системы). Указывая `0` говорим что её вообеще не надо проверять, `1` - самой первой (обычно для  `\`) и наконец `2` если проверять, но после первой.
