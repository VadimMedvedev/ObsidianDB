
Есть разные способы дистрибуции (установки/распространения) программного обеспечения:
1) **Инстолятор.** Содержит сущность развёртывающее приложение.
2) **Установочный пакет.** Обычно, он содержит всё нужное для установки и работы программного обеспечения (библиотеки, зависимости и т.д.). 
Например те же библиотеки dll, которые используються для компиляции и запуска продукта. Для каждой программы зачастую нужна своя версия библиотеки, но скачивать отдельно и хранить их всех по отдельности - не вариант. Лучше хранить все зависимости в одном месте, и каждый раз при установки приложения ставить только отсутствующие библиотеки.

Так как всё ПО зависит от версий библиотек и т.д., то были придуманы репозитории. Репозиторий это место где хранится всё ПО специально перекомпелированное для специальной конфигурации версий библиотек.
У каждого дистрибутива Линукс свой репозиторий, который обновляется и поддерживается мейнтейнерами. Таким образом при устаноки пакетов из репозитория, ПО работает корректно.
Если выходит новая версия библиотеки, то мейнтейнеры пересобирают все пакеты зависящие от неё.

Помимо самого ПО, пакеты хранят:
1) Конфигурационные файлы
2) Управляющая информация (используется для развёртки)
3) Контрольные суммы всех файлов
4) Постустановочные скрипты
5) Скрипты, вызываемые перед удалением пакета
6) Скрпиты, вызываемые после удаления пакета
Всё это содержится в одном файле (в debian с расширением .deb).
