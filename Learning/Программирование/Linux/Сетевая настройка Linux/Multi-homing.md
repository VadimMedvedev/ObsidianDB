
Multi-homing - когда у устройства есть сразу несколько сетевых карточек и он подключен к нескольким локальным сетям.
Тогда возникает много проблем для маршрутизации, которые надо настраивать.
Основная проблема: асимметричный маршрутизация - запрос пришёл с одного интерфейса а ответ отправился на другой. В такой ситуации может возникнуть много проблем. Ответные пакеты на обратном пути могут посчитаться спуфингом (потому что приходят с другого адреса)
Для такой настройки используется Policy-based Routing (PBR). Для этого содаётся несколько таблиц маршрутизации и настраиваются их политики

### Настройка политик

Для этого надо для начала установить пакет `iproute2`.
Затем надо указать нужные таблицы в файле `/etc/iproute2/rt_tables` (по умолчанию эта директория и файл могут быть не созданными). В формате число название указываются все используемые таблицы (номер может быть от 1 до 252):
```
100 table1
200 table2
```

Все статические маршруты для каждой таблицы настраиваются как обычно, с указанием таблицы через `table <название>`.

Для настройки самой политики мы используем команду:
``` bash
ip rule add from <ip адрес интерфейса/32> table <название> priority <значение>
```
Таким образом все пакеты полученные на указанном интерфейсе будут маршрутизироваться согласна указанной таблицы.
