
### Команда nslookup

Показывает ответы с DNS сервера.

`nslookup google.com`
Возвращает все ipv4 и ipv6 адреса соответсвующие данному доменному имени.

Можно получить информацию по кокретным типам записи про это доменное имя:
`nslookup -type=NS google.com`

Обратный просмотр по IP.
`nslookup 8.8.8.8`

Вторым аргументом можно указать конкретный dns сервер, у которого мы спросим
`nslookup google.com 1.1.1.1`

С ключом `-debug` показывает дополнительные детали

### Подробный dig

`dig google.com [A | AAAA | NS | ...]` - вывод конкретных записей. Вывод намного информативнее чем у nslookup. Поумолчанию ищет записи A.
`dig @<адрес> google.com` - указываем от какого сервера получать инфу.
`dig -f <путь до файла>` - находит записи по этим доменным именам

Есть пару нужных ключей:
`+trace` - показывает полный путь разрешения имени с корневых dns серверов.
`+short` - показывает короткую форму

### Простой и удобный host

`host google.com` - базовый запрос
`host -t MX google.com` - запроc конкретного типа
`host -a google.com` - получить все типы записей
`host 8.8.8.8` - обратный запрос
`host google.com 8.8.8.8` - запрос у конкретного dns сервера
