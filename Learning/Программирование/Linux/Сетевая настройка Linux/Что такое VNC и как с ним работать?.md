
**VNC (Virtual Network Computing)** — это технология удалённого доступа к графическому рабочему столу. Она позволяет видеть и управлять интерфейсом другого компьютера так, будто ты сидишь прямо за ним.

VNC работает по модели **клиент–сервер**:
- **VNC Server** — запущен на удалённой машине (к которой подключаются)
- **VNC Viewer (Client)** — программа, с которой ты подключаешься

Принцип работы очень прост:
1. Сервер **считывает содержимое экрана** (framebuffer)
2. Отправляет клиенту **изображение экрана**
3. Клиент отображает картинку
4. Действия пользователя (мышь/клавиатура) отправляются обратно на сервер

Есть много реализаций этой технологии:
- TigerVNC — быстрый, open-source
- RealVNC — коммерческий
- TightVNC — лёгкий, сжатие трафика

### Команды

Команды тривиальные. На стороне сервера нужно открыть порт для подключения:
```
vncserver :0
``` 
А на клиенте соответсвенно подключится:
```
vncviewer ip-addr:0
```
Порт здесь конечно "виртуальный", он конвертируется в настоящий по формуле 5900 + virport.
