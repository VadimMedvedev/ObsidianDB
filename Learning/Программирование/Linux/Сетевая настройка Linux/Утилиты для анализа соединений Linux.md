
### Команда netstat

`netstat -tulpn` - наиболее часто используемая команда
Здесь ключи значат:
* `-t` - показывать tcp соединения
* `-u` - показывать udp соединения
* `-l` - показывать прослушиваемые (listen) соединения, иначе показывает не прослушиваемые
* `-p` - показывать какая программа установила соединение
* `-n` - не заменять порты названиями протоколов

### Команда lsof

`lsof -i :80` -  показывает процессы использующие порт 80
`lsof -i` - все сетевые соединения
`lsof -i {tcp|udp}` - конкретные типы подключения
`lsof -i @<адрес>` - все соединения с сервером
`lsof -p <значение>` - все файлы открытые процессом, с заданным портом

### Команда nc

`nc -zv <адрес> {<порт>|<диапозон-портов>}` - проверяет открыты ли на серваке порты
