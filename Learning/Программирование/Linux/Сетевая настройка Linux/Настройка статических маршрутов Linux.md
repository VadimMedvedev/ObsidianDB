
### Просмотр всех маршрутов

``` bash
ip route show
```
или 
``` bash
ip r
```
Показывает все маршруты настроенные на данном устройстве

### Создание маршрута

Общий синтаксис
``` bash
ip route add <адрес сети назначения/префикс> via <адрес устройства> dev <название интерфейса> [параметры]
```
Особенности:
* Можно не указывать интерфейс (тогда будет сам искать интерфейс, через который можно отправить пакет до устройства)
*  Для маршрута по умолчанию, заместо адреса сети пишем `default` или указываем адрес `0.0.0.0/0`
* Если сеть подключена напрямую, то можно не указывать адрес следующего устройства маршрутизации (via и адрес). В таком случае пакет будет искать получателя в этой сети

### Удаление маршпутов

Для этого надо указать два определяющих параметра каждого маршрута: это адрес сети и адрес следующего устройства адресации:
``` bash
ip route del <адрес сети/префикс> via <адрес следующего хопа>
```

### Дополнительные параметры

`src <адрес>` - правило маршрутизации перенаправляет по особым правилам ip пакеты именно этого отправителя
`metric <значение>` - указывает стоимость маршрута (меньше лучше)
`table <значение>` - настройка конкретной таблицы маршрутизации (используется для [[multi-homing]])
`scope {link | global | host}` - определяет достижимость этого адреса. Например параметр `host` - говорит что это адрес самого локального компьютера, это используется например для loopback. `link` - означает, что сеть подключена напрямую, и пакет не будет отправляться на следующий хоп, заместо этого  устройство будет делать arp запрос и отправлять коммутатору кадр для переправки. Параметр `global` говорит что next-hop необходим.
`proto {kernel | static | dhcp}` - определяет кем назначен маршрут: ядром, dhcp или вручную администратором
`mtu <число>` - указать ограничение передачи данных по каналу

### Временные и постоянные маршруты

Маршруты добавляемые командой `ip route add` - временные.
Установка постоянного маршрута зависит от дистрибутива, везде по разному.
