
### Команды head и tail

Команда head -<число> выведет n первых строк, команда tail -<число> последние n строк. Выводит в [[Стандартный ввод и вывод|стандартный вывод]] и либо получает из файла в аргумнте, либо же из стандартного ввода.
Следующие команды делают одно и тоже:
``` bash
cat file | head -3
head -3 file
```

Ключ -f при обновлении файла, сразу показывает его изменения в выводе. Как бы транслирует содержимое файла и как оно меняется динамически.

### Команда more

Пролистывает файл только вниз.

### Команда less

Открывает среду для просмотра текста. Текст можно листать вверх вниз. Текст берёться из [[Стандартный ввод и вывод|стандартного ввода]] или из указанного файла.

Основной функционал:
1) Стрелочки и page up/down - пролистывание
2) написав /<слово> он выделит все включения этого слова в тексте.
3) q - выход.

Дополненный more.
