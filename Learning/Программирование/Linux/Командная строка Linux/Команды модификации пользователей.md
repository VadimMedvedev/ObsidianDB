
### Команда usermod

Эта команда используется для изменения настроек [[Пользователи в Linux|пользователя]], у неё есть следующие ключи, определяющие что она изменит:
* -d /path/to/dir - изменяет домашнюю директорию на указанную
* -m - переносит все файлы из старой в новую директорию (используется только с d)
* -l <имя> - устанавливает новое имя пользователя
* -s <шел> - ставит по умолчанию новый [[shell|шел]] пользователю.

Пример:
``` bash
usermod igor -md /home/new_home
```

### Команда userdel

Команда удаляет пользователя по имени:

``` bash
userdel igor
```

Но при таком удалении домашняя директория пользователя останется. Чтобы удалить всё связанное с этим пользователем используем ключ -r.
