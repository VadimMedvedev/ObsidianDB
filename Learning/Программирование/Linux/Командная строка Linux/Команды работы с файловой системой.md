
### Команда ls

Команда ls выводит список содержимого директории. 
По умолчанию, это директория в которой находится пользователь, но можно указать и другую директории или даже файл (выведится информация об этом файле), написав её в аргументе.
Также у команды ls есть много полезных ключей. Например:
* -l - для дитального вывода файлов в директории
* -F - для вывода типов файлов
* -a - выводит все файлы в директории включая скрытые

При выводе -l можно ещё увидеть [[Символические и жёсткие ссылки|кол-во точек входа (жёстких ссылок)]], на этот файл.

### Команда cd

cd - change directory

1) cd .. - мы переходим на директорию выше (выходим из настоящей папки)
2) cd - возвращаемся в домашнюю директорию
3) cd path/to/dir - переносит нас в эту директорию

### Команда mount

Эта команда [[Монтирование файловых систем|монтирует]] устройство к файловой системе компьютера.

``` bash
mount /dev/device_name /path/to/dir
```

Первый аргумент это файл устройства, а второй - это директория, к которой мы прикрепляем этот файл.
При этом к файлам, которые лежали в этой директории, теперь нельзя будет получиться доступ до окончания монтирования.

Ключи:
* -r - readonly, файловую систему можно только читать.

### Команда umount

Отмантирует от директории файловую систему

``` bash
umount /path/to/dir
```

Иногда система може поругаться: target is busy, но это значит что либо какой-то процесс работает в этой файловой системе, либо же какой-то пользователь в ней стоит. Для отмонтирования нужно завершить все процессы в ней и выгнать всех пользователей.
