
### Команда mkdir

Создаёт директорию в текущей директории:
``` bash
mkdir newdir
```

Можно создавать несколько вложенных каталогов многовенно при помощи ключа p:
``` bash
mkdir -p dir1/dir2/dir3
```
Если бы директории dir1 и dir2 не были бы созданы заранее и мы бы не написали ключ p, то команда бы пожаловалась на отсутствие директории dir1/dir2.

### Команда rmdir

Эта команда удаляет **пустые** директори:
``` bash
rmdir newdir
```

Если каталог не пуст, то будет ругаться (в таком случае лучше использовать rm -rf dirname).

Аналогично как и для mkdir есть ключ p, который удаляет все катеории последовательно (по сути обратная команда.). Но если в них что-то кроме директорий есть, то не сработает, будет ругаться на непустоту.
