
### Информация о группах

Получить информацию о группах можно получить в файле [[Группы в Linux|/etc/group]].
Группы, к которым принадлежит тот или иной пользователь, можно посмотреть командой groups:
``` bash
groups user_name
```
Первая после двоеточия будет указан [[Группы в Linux|первичная группа]] пользователя, затем будут перечисляться вторичные.
### Команда addgroup

Эта команда создаёт в системе группу с данным именем и придаёт ей свободный [[Группы в Linux|gid]]:
``` bash
addgroup group_name
```

### Изменение групп пользователя

Для этого используется уже известная [[Команды модификации пользователей|команда usermod]] но используются следующие ключи:
* -g group_name - изменение первичной группы пользователя
* -G group_name1, group_name2, ... - добавит пользователя в данные группы, но удалит из тех, в которых он был
* -a - добавит группы из ключа -G, не выкидывая из старых.

### Команда groupdel

Эта команда удаляет заданную группу, но система не при каких условиях не даст удалить чью-нибудь первичную группу.
