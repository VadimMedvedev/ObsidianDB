
### Команда ps

Эта команда выводит все процессы запущенные в данный момент от имени пользователя в этом терминале.
Мы видим [[Процессы в Linux|pid]], терминал (tty) с которого это было запущено, процессорное время выполнения и команда, которая вызвала процесс.
``` bash
ps
```

Через ключ u мы можем посмотреть все процессы запущенные другими пользователями:
``` bash
ps -u user_name
```

Чтобы посмотреть все процессы используем ключ -A:
``` bash
ps -A
```

Ключ -x показывает все процессы пользователя вместе с [[Состояния процессов|сосотояниями]]:
``` bash
ps -x
```

Чтобы вывести всю информацию о идущих сейчас процессах используется команда:
``` bash
ps aux
```

### Команда top

Динамически показывает все процессы сейчас идущие с большим количеством информации.
Есть дополнительные ключи:
* -u user_name - выводит все процессы данного пользователя

### Команда nice

Эта команда запускает процессы с определённым [[Приоритет процессов|уровнем приоритета]] (он задаётся через ключ -n):
``` bash
nice -n 11 command
```

### Команда renice

Эта команда изменяет приоритет уже запущенного процесса. Для этого нужно знать pid этого процесса (можно посмотреть через top или ps).
``` bash
renice -n 3 -p pid
```

### Команда kill

Простое использование:
``` bash
kill pid
```
Так, команда подаёт процессу сигнал "умри" и процесс завершается.
