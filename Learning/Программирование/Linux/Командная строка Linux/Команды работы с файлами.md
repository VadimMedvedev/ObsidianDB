
# Команда cat

Программа cat просто выводит содержимое файлов написанных после неё. Так выглядит её синтаксис:

``` Bash
cat file1 file2
```

Программа названа cat, потому что при печатии содержимого нескольких файлов она их конакатенирует, соединяет (con**cat**enation).

Если не указывать никакого файла, то cat будет читать из стандартного ввода, т.е. из консоли всё что мы напишем (для заверешения ctrl + D).

### Команда cp

В самой простой форме, cp копирует содержимое file1 в file2, для этого надо ввести:
``` Bash
cp file1 file2
```

Можно также скопировать файл в другую директорию, оставляя прежнее название:
``` Bash
cp file dir
```

Для того, чтобы скопировать сразу несколько файлов, можно написать:
``` Bash
cp file1 file2 file3 dir
```

* **Ключ r** копирует директорию и всё содержимое в ней вместе с другими директориями рекурсивно.
* **Ключ u** скопирует только новые версии файлов, если же в мест копирования есть файл с таким же названием более новой версии (временной штамп стоит позже), то копирование не произойдёт. Т.е. если мы копируем целую папку с множеством файлов в уже существующую, изменятся только те, у которых временной штамп старее.

### Команда mv

Команда mv (move) перемещает файл (т.е. посути копирует, и удаляет старый файл). В самой простой форме, она переименовывает файл (т.е. пермещает в ту же папку, но с другим именем):
``` Bash
mv file1 file2
```

Можно перемещать файл в разные директории как и в случае команды cp.

### Команда touch

Команда touch обновляет время изменение файла на текущее. Но если такого файла нет, то она создаст его пустым. Поэтому touch часто использую для быстрого создания пустого файла.
``` Bash
touch file
```

Ключ t позволяет изменить методанные файла на новые. Пример
``` bash
touch -t 202502161200 file
```
Дата и время пишутся слитно.

Ключ r копирует метаданные об изменении файла на другой файл
``` bash
touch -r file1 file2
```

### Команда rm

Команда rm (remove) удаляет файл. После этого, файл невозможно будет востановить (только если не использовать бэкапы).
``` Bash
rm file
```

### Команда file

Выводит информацию о файле

``` bash
file filename
```

### Команда ln

Создаёт [[Символические и жёсткие ссылки|ссылку]] (по умолчанию [[Символические и жёсткие ссылки|жёсткую]]). 
Пример:
``` bash
ln file link_to_file # теперь файл link_to_file будет жёсткой ссылкой на file
ln -s file link_to_file # Ключ -s (soft) делает ссылку символической
```
