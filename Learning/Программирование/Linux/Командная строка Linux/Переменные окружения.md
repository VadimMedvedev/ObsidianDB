

### Работа с переменными окружениями

Чтобы вызвать значение той или иной переменной окружения, нужно обратится к ней со знаком $.
``` bash
echo $PWD # Выведет значение переменной PWD
```

При помощи команды export, можно присвоить переменным окружения новые значения (и инициализировать новые)
``` bash
export NEWVAR=value
```
Но изменения будут хранится только до конца сессии. Чтобы изменения сохранились, можно записать эту строчку в [[Файл .bashrc|файл .bashrc]] (точнее значения переменных каждый раз будут выставляться так при запуске bash).

### Основные переменные окружения

* PATH — **переменная окружения**, которая содержит список каталогов, разделенных двоеточиями :. Когда вы вводите команду в терминале, система последовательно проверяет эти каталоги на наличие исполняемого файла с таким именем.


### Примеры

Иногда, у обычных пользователей в PATH не записаны директории, в которых хранятся красноглазые команды, это можно исправить следующим образом:
``` bash
echo 'export PATH=$PATH:/usr/sbin' >> ~/.bashrc
```
