
Глоббинг это подстановка нескольких файлов подходящих к регулярному выржаению в аргументы команды. Глоббинг обрабатываеться перед выполнением команды, на этапе обработки написанной команды shell.

### Основные знаки

1. \* - Любое количество любых символов
2. ? - Ровно один любой символ
3. \[\] -Один символ из указанных
4. Диапазоны \[a-z\], \[0-9\]
5. Исключение \[!\] или \[^\]

Примеры:
ls \*data\*       # все файлы, содержащие "data" в имени
ls image?.jpg   # image1.jpg, imageA.jpg
ls \[abc\]\*.txt        # файлы, начинающиеся на a, b или c
ls \[A-Z\]\*.pdf         # файлы PDF, начинающиеся с заглавной буквы
ls file\[!0-9\].txt    # все fileX.txt, где X не цифра

### Как это работает

Пример: ls \*.txt
1. Bash "видит" шаблон \*.txt
2. Сканирует текущую директорию
3. Ищет файлы, имена которых соответствуют шаблону
4. Собирает список: file1.txt, file2.txt, notes.txt
5. Шаблон заменяется списком файлов: ls \*.txt → ls file1.txt file2.txt notes.txt
