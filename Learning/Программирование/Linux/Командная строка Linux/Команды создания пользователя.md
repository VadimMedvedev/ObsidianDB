
### Команда useradd

Добавляет [[Пользователи в Linux|пользователя]] в систему:
``` bash
useradd igor
```

Результат в файле /etc/passwd:
```
igor:x:1001:1001::/home/igor:/bin/sh
```

При этом пользователю не присваивается пароль и домашняя директория не создаётся. Пользователь даже не сможет войти в систему.

### Команда passwd

Меняет пароль пользователя, или же, если его не было, то просто устанавливает его:
``` bash
passwd igor
```


## Процесс создание пользователя

Чтобы сделать базовую настройку нового пользователя, нужно как минимум выполнить три команды:

``` bash
useradd igor
passwd igor
mkdir /home/igor
```

useradd - пример низкоуровневой утилиты, которая делает какой-то маленький кусочек. Утилита adduser позволяет автоматизировать и ускорить этот процесс

### Команда adduser

``` bash
adduser igor
```

Это интерактивная команда, которая попросит сразу ввести пароль для пользователя и т.д. во время её работы. Она сразу создаст директорию и! даже вставит "скелет" домашней директории, т.е. такие папки как видео, документы и т.д. в windows. 
Все файлы и директории, которые по умолчанию поставятся в домашнюю директорию копируються из /etc/skel, таким образом можно самим настраивать конфигурацию по умолчанию.

### Ключи для useradd

Но у useradd тоже есть возможность создать пользователя сразу с домашней директорией и т.д.

``` bash
useradd lkiff -m -d /home/kliff -k /etc/skel -s /bin/bash
```
Здесь:
* Ключ -m отвечает за то, чтобы создать домашнюю директорию. По умолчанию она создаст директорию /home/<имя пользователя> и загрузит в неё файлы из /etc/skel.
* Ключ -d уточняет какую именно домашнюю директорию для пользователя сделать
* Ключ -k уточняет какую директорию испольщовать как шаблон (по умолчанию /etc/skel)
* -s говорит какой [[Shell|shell]] будет использовать пользователь.
