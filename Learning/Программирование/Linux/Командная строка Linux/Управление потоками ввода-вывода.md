
Каждая команда, по сути, обрабатывает данные из потока ввода и возвращает их в поток вывода. По умолчанию часто этими потоками длявяються [[Стандартный ввод и вывод|стандартные потоки ввода вывода]] (если не указано иного), которые зависят от среды в которой запущен shell.
Этими потоками можно упралвять, вот основные инструменты:
* | - отправляет данные из потока вывода слева в поток ввода справа.
* > - результат потока вывода слева записывает в файл.
* >> - тоже самое, но добавляет в конец файла и не стирает все старые данные.
* <  -  стандартный ввод для команды слева берёт из файла справа
