
Чтобы вызвать любую команду в [[Процессы в Linux|фоновом процессе]] в конце надо поставить символ &. Например:
``` bash
sleep 10000 &
```
Теперь программа, которая просто спит 10000 секунд работает в фоновом режиме.

### Комманда jobs

Чтобы посмотреть все процессы в фоновом режиме ([[Процессы в Linux|джобы]]) можно ввести команду:
``` bash
jobs
```

Она также показывает внутреннию нумерацию этих процессов

### Команда fg

Чтобы вызвать джобу из фонового режима на передний план пишем команду:
``` bash
fg %номер job
```

Номер job указан в квадратных скобках в выводе jobs.

### Команда bg

Запускает остановленный процесс:
``` bash
bg %номер job
```
