
### Команда chmod

Эта команда позволяет редактировать [[Избирательные права доступа DAC|права доступа]] над файлом.

Самый популярный способ работы с данной командой при помози числовых значений. Каждый набор прав можно представить в двоичной системе, право либо есть либо нет, 1 или 0. Таким образом каждый набор rwx можно представить числом от 0 до 7. Пример r-x = 101$_2$ = 5. Таким образом все три набора можно задать при помощи трёхзначного числа.
Перый же бит определяющий тип файла можно задать так:
* 0, если это обычный файл (в записи символ -)

Пример:
``` bash
chmod 0761 file_name
```
Владелец теперь имеет все права над этим файлом, все пользователи принадлежащие первичной группе могут делать всё с ним, только не исполнять, а все остальные могут только исполнять этот файл.

Ключ -R позволяет установить права рекурсивно.
``` bash
chmod -R 777 dir_name
```
Тогда у всех файлов и директорий любого уровня вложенности в директории dir_name установятся права 777.

##### Другие способы задания прав

Обозначения наборов:
1) u (user) - владелец
2) g (group) - пользователи из первичной группы владельца
3) o (other) - другие пользователи
4) a (all) - все наборы

Можно напрямую задавать для определённых груп пользователей права:
``` bash
chmod u=rw,o=r file
```
Права пользователей из ПГ владельца не изменятся.

или же
``` bash
chmod a=rw file
```

При этом, у неуказанных наборов права останутся теми же.

Разберём получше символы:
* =  - перезапишет новые права данному набору
* + - добавит права, не удалив старые
* - - уберёт указанные права

Пример:
``` bash
chmod u=r,g+wx,o-r file
```
Владелец теперь может только читать, пользователи из ПГ теперь смогут редактировать и выполнять, а другие больше не смогут читать.

#### Дополнительные права доступа

Чтобы установить [[SUID, SGID и Sticky bit|дополнительные права доступа: sticky bit, suid, sgid]] необходимо в числовой записи заместо 0 передать
* 1 - для включения sticky bit

Пример:
``` bash
chmod 1777 file # Устанавливает sticky bit на директорию
```


### Команда chown

Эта команда меняет владельца файла, из-за чего конечно доступ к файлу для разных пользователей изменится (так как он зависит от владельца файла).
Но даже сам владелец файла не может поменять владельца, такие права никому не доступны кроме root.
``` bash
chown user file_name
```
Но при этом группа для второго набора останется прежней, т.е. [[Группы в Linux|первичной группой]] создателя.

Более того, можно даже менять группу, к которым будут применятся права из второго набора
``` bash
chmod user:group file_name
```
Как изместно, по умолчанию ставится первичная группа создатея этого файла.

Наконец синтаксис:
``` bash
chmod user: file_name
```
позволяет изменить как владельца файла, так и группу на первичную группу указанного пользователя
