
Есть несколько разных команд для вывода документаций о разных командах, устройствах и т.д. в системе.

### Ключ --help

Для большенства команда существует ключ --help который выводит краткую справочную информацию о команде

### Команда man

Эта команда может и не присутствовать в сжатой версии системы, её надо устанавливать из пакета! В archlinux это mandoc.
Эта команда выводит подробную справочную информацию о команде или другом объекте в системе. По сути это мануал в котором много записей, т.е. встроенная вики.
