
Чтобы заблокировать [[Пользователи в Linux|пользователя]] можно использовать [[Команды модификации пользователей|команду usermod]] с ключом -L. Пример:
``` bash
usermod -L igor
```

Заблокированные пользователи не смогут войти в систему. При входе им будут писать, что логин некорректен.

Ключом -U пользователя можно разблокировать:
``` bash
usermod -U igor
```

Можно запланировать блокировку пользователя на определённый день (т.е. поставить срок действия учётной записи):
``` bash
usermod igor -e 2026-12-20
```

Посмотреть информацию о том, когда истекает срок дейсвтия учётной записи можно командой:
``` bash
chage -l igor
```
