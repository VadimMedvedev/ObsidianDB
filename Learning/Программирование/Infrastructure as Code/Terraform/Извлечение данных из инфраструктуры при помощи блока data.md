
Некоторые провайдеры предоставляют возможность получения некоторых данных через блоки `data`. Типы этих блоков и их параметры можно найти в документации провайдера.

### Принцип работы

Terraform пытаеться получить данные в течении планирования, но может и отложить это до момента применения (apply) инфраструктуры, если так указано. Это будет отображаться в плане.
Сама terraform откладывает получение данных, если оно зависит от ещё не созданных ресурсов, или ресурсов которые должны будут быть изменены.

### Создание блока data

Для создания блока `data` мы должны указать его тип (см. документацию провайдера), его локальное название и задать его аргументы (какие аргументы нужны каждому типу блока `data` см. в документации).

``` HCL
data "aws_ami" "example" {
  # . . .
}
```

### Обращение к полученным данным

Для обращения к данным использвем запись `data.<TYPE>.<LABEL>.<ATTRIBUTE>`. В случае предыдущего примера, если мы захотим обратиться к атрибуту `id` данных (у полученного блока данных может быть несколько атрибутов), мы воспользуемся записью `data.aws_ami.example.id`.

### Мета аргументы блока data

Для более подробного описания создания инфраструктуры, можно указывать terraform нюансы по её созданию. Например:
##### depends_on
В аргументе `depends_on` мы можем указать список ресурсов, которые требуется создать, перед тем как данные будут запрошены.
##### provider
В этом аргументе можно указывать конкретного провайдера через псевдоним `<PROVIDER>.<ALIAS>`. См. [[Объявление провайдера блоком provider|использование нескольких провайдеров]].

Можно управлять жизненым циклом (lifecycle) блока data при помощи вложенного блока `lifecycle`. В нём например можно задать:
##### precondition
Вложенный блок в `lifecycle`. В нём прописываються аргументы `condition` и `error_message`. Эта проверка, которая будет осуществляться перед самым получением данных
##### postcondition
Тоже самое, но эта проверка будет проводиться после получения данных. В ней можно использовать `self` для обращения к самому себе (т.е. заместо `data.<TYPE>.<LABEL>`).
