
Terraform вызывается в некоторой директории где хранятся конфигуарционные файлы инфраструктуры. Эта директория становится его рабочей средой. В ней он хранит кэш и файлы состояний (отображающие состояние инфраструктуры на данный момент).

Инциализровать рабочую директорию необходимо до применения любых изменений инфраструктуры.

### Содержимое рабочей директории

Рабочая директория Terraform обычно хранит:
* Файлы конфигурации, в которых описаны [[Создание и управление ресурсами Terraform|ресурсы]] инфраструктуры.
* Спрятанная директория .terraform, которая используется terraform для хранения своей личной информаци для данной инициализированной рабочей среды. Она появляется сразу после первой инициализации.
* Данные о предыдущих конфигурациях инфраструктуры, если они хранятся локально (т.е. не используется [[Terraform издания|HCP Terraform]]). Terraform управляет состояниями в terraform.tfstate, если используется только одна рабочая среда, и в директории terraform.tfstate.d, если несколько.

### Инициализация 

Для инциализации достаточно использовать команду `terraform init`. После этого можно спокойно переходить к [[Основной принцип работы Terraform|обычному циклу использования terraform]].

В течении инициализации происходит подготовка директории к хранению состояний, скачивание необходимых провайдеров и скачивание модулей.

### Реинициализация 

Некоторые изменения в конфигурации требуют повторной инциализации. Например изменение списков используемых провайдеров (новые нужно скачать) или использование новых модулей.
Для повторной инициализации мы также используем команду `terraform init`.
