
Конфигурационный язык terraform поддерживается во всех [[Terraform издания|изданиях terraform]]. Он служит общим языком для описания инфраструктуры для любых возможных платформ. 
Он говорит что надо создать, какие плагины подгрузить, как связать разные ресурсы.

### Основные правила

Основная цель этого языка, это объявление [[Создание и управление ресурсами Terraform|ресурсов]]. Все остальные особенности языка сделаны только для удобства и гибкости создания ресурсов.

Синтаксис языка состоит из нескольких основных элементов:
``` HCL
resource "aws_vpc" "main" {
  cidr_block = var.base_cidr_block
}

<BLOCK TYPE> "<BLOCK LABEL>" "<BLOCK LABEL>" {
  # Block body
  <IDENTIFIER> = <EXPRESSION> # Argument
}
```

* **Блоки** хранят разные данные и представляют из себя некоторый объект, например ресурс. У каждого блока есть тип, несколько лейблов/названий (или даже ноль), а также тело блока, которое может иметь любое количество аргументов и другие вложенные блоки.
* **Аргументы** присваивают значения некоторым именам. Они появляются в блоках.
* **Выражения** представляют из себя значения, или комбинацию зачений. Они появляются как значение для аргументов.

Порядок блоков не имеет значения, так как язык декларативный, и он сам решает как реализовывать на практике описанную нами инфраструктуру, а не тупо идёт по списку блоков.
