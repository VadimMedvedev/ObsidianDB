
Иногда terraform требует для работы **чувствительные данные** (секретные данные). Например ssh ключ или API токен и т.д. Держать такие данные в самих конфигурационных файлах - опасно (т.к. они будут храниться в общем репозитории). Есть несколько вариантов сделать безопасным использование таких данных.

### Чувствительные данные в state файле и в плане

В файле state будут храниться все чувствительные данные, по этому с ним надо обходиться аккуратно. Например, если работа ведёться только одним человеком локально, то эти файлы стоит исключить из коммитов (.gitignore). Если же идёт командная работа, то можно хранить state файлы удалённо, испольщзуя например HCP Terraform, который будет автоматически их ещё и шифровать.

Более того, при выводе плана terraform также будет показывать все данные по умолчанию.

### Скрытый вывод переменных

Для хранения и вывода чувствительных данных используется аргумент `sensitive` со значением true в блоках `variable` и  `output`. Тогда при выводах output и в плане все эти переменные будут цензурироваться. 
Но при этом эти данные всё равно будут храниться в state файле и в плане.
