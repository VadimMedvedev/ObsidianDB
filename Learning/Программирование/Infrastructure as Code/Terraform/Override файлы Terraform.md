
Terraform запускает все файлы в рабочей директории с расширением `.tf` одновременно. Если при этом происходит определение объекта несколько раз, то terraform выдаёт ошибку.

Иногда, удобно переписывать изначальные объекты, и предавать им другие свойства. Для таких редких ситуаций, используются файлы с названиями оканчивающимися на `_override.tf` и файл `override.tf`.

Сначала terraform обработает все обычные файлы, а потом уже будет применять изменения из override файлов. В таком случае, он уже не будет выдавать ошибку при переопределении объектов. Он их будет дополнять!

### Дополнение объектов

При использовании override файлов, старые объекты не будут полностью переписываться, они будут дополнятся!

Такие правила при этом используються:
* Дополнение будет происходить, только если для перезаписываемого блока найдётся блок из нормального файла, чей **заголовок** ([[Синтаксис языка Terraform|тип]] и все [[Синтаксис языка Terraform|лейблы]] одинаковые) будут совпадать.
* [[Синтаксис языка Terraform|Аргументы]] из блока в файле override заменят аргументы с такими же названиями в изначальном блоке. Остальные остаються неизменными.
* Все вложенные блоки одного типа из override блока заменят все вложенные блоки этого типа в изначальном блоке.
* Содержимое вложенных блоков не дополняется, а полностью перезаписывается.

Если сразу в нескольких местах идёт перезапись одного и того же объекта, то они вместе будут применяться. Притом большую силу имеют последнии изменения (все фалы override обрабатываються в алфавитном порядке, внутри них порядок перезаписи совпадает с порядком объявления блоков).

### Особые правила

Для разных типов блоков есть свои особые правила перезаписи. См. в [докуменатцию](https://developer.hashicorp.com/terraform/language/files/override).
