
Есть три возможности работы с Terraform:

## Terraform Community Edition

Это бесплатная версия, позволяющая работать с terraform из командной строки. Она вклюяает весь основной функционал.
* Использование общего конфигурационного языка для создания ресурсов на любых поддерживаемых провайдерами платформах.
* Отслеживание версий инфраструктуры.
* Использование и публикация модулей.

## HCP Terraform

Это сервис для удалённого запуска terraform, который можно синхронизировать с любыми системами контроля версий. Большенство фишек HCP Terraform доступно бесплатно для маленьких команд. Для больших команд есть платный план с дополнительными услугами.
* HCP Terraform можно встраивать при помощи API в свой пайплайн.
* В HCP Terraform своя регистрация, которая позволяет настривает права и доступ над зарегестрированными пользователями.
* Защищённо хранит всю историю изменений инфраструктуры.
* Внутренее хранилище модулей.
* Настройка прав редактирования инфраструктуры при помози Sentinel.

## Terraform Enterprise

Позволяет создавать свои HCP Terraform локальные сервера и поддерживает их.
