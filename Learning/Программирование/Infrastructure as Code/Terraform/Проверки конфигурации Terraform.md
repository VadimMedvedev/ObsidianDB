
Во время работы модуля, хорошо отслеживать и проверять, как происходит установка, и не происходит ли каких-то не прдномеренных ситуаций.
В terraform предусмотренны следующие способы проверки процесса развёртывания конфигурации:
* Проверка корректности полученных значений [[Создание интерфейса модуля Terraform при помощи переменных|переменных]].
* Проверка готовности инфраструктуры к установке ресурса.
* Постпроверка ресурса после установки, всё ли установилось верно?
* Проверка работы всей инфраструктуры в целом.

Для каждого провала проверки можно указать сообщение ошибки, что бы пользователю было легче разобраться в ней.

### Проверка ввода значений в переменные

Для этого, в блоке `variable` используються вложенные блоки `validation` (см [[Создание интерфейса модуля Terraform при помощи переменных|определение переменной]]). В них указываються условия `condition`, под которые должно подходить значение переменной и ошибка `error_message`, которая будет выведена если условие не соблюдено.
Чтобы обратиться к значению переменной в условии мы, как и везде, используем `var.<VAR_NAME>`.

### Способы задания условия

В качестве условия, мы можем записать любое выражение возвращающее булевые значения `true` или `false`.
Для этого можно использовать любые операторы и функции.
Среди основных операторов:
* `||`, `&&`, `!` - логические операторы (работают ровно также как и в языках программирования)
* `>`, `>=`, `<=`, `<`, `==`, `!=` - операторы сравнения (как в Python)
При этом, между значениями можно также использовать операторы `+`, `-`, `*`, `/`, `%` (конечно если они определны для данных типов).
Также в выражении можно вызывать функции. Пару примеров функций:
* `contains([str, ..., str], str)` -  возвращает true, если хотя бы одна из подстрок из списка находиться в строке.
* `length(str)` - возвращает длину строки (целое число `int`).
