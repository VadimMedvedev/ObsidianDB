
После того, как мы [[Перечисление провайдеров в блоке terraform|указали всех необходимых провайдеров]] мы должны их объявить в коде. Для этого используется блок `provider`.

### Блок provider

Общий синтаксис блока `provider` выглядит так:
``` HCL
provider "<PROVIDER_NAME>" {
  <PROVIDER_ARGUMENTS>
  alias   = "<ALIAS_NAME>"
  version = "<VERSION_CONSTRAINT>"  # Deprecated
}
```

Под именем провайдера, предпологается локальное имя, данное ему при [[Перечисление провайдеров в блоке terraform|указании его в блоке terraform]].
* У каждого провайдера есть свои аргументы которые нужно указывать, они прописаны в документации провайдера.
* Аргумент `alias` опционален, он принимает уникальный идентификатор, что позволяет использовать одного провайдера несколько раз в инфраструктуре. Тогда обращаться к конкретному провайдеру надо будет через `<PROVIDER_NAME>.<ALIAS>`. Если используется несколько псевдонимов, то при обращении просто по имени провайдера будет подразумеваться тот, у которого псевдоним не прописан. В случае, когда мы не хотим использовать дефолтного провайдера для ресурсов, блоков данных и т.д., используется мета аргумент `provider`, в котором записываеться `<PROVIDER_NAME>.<ALIAS>`.
* Аргумент `version` являеться устаревшим, сейчас не используется.
