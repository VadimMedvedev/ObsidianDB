
Весь код терраформ хранится в файлах с расширением `.tf`. Если он записан в формате JSON, то файл должен заканчиватся на `.tf.json`.

### Модули и директории

Модуль - это нескольк `.tf` и/или `.tf.json` файлов лежащих в одной директории. Все вложенные директории считаються уже другими модулями, и изначльно не включаються модуль родительской директории.
Terraform рассматривает каждый модуль как один документ. Ему не важно в какие файлы разнесены различные блоки, это нужно только для простоты чтения и масштабирования.

Модули могут использовать другие модули, чтобы вклчюать их в конфигурацию. Можно ссылаться как на модули в локальной директории (он может лежать в любом месте), так и на модули из [[Что такое Terraform?|Terraform Registry]].

### Root модуль

Terraform всегда запускает [[Инициализация рабочей директории|рабочую директорию]] как root модуль. Все остальные директории воспринимаются как модули.
