
Чтобы пользоваться модулями некоторой коллекции, для начала эту коллекцию необходимо установить. Т.е. управление модулями производится на уровне коллекций. Чтобы использовать один модуль надо скачать всю коллекцию.

Для работы с коллекциями используется утилита `ansible-galaxy` и её команда `collection`. Есть несколько возможных действий с коллекцией:
* `list` - показывает все установленные коллекции
* `install название_коллекции` - установка
