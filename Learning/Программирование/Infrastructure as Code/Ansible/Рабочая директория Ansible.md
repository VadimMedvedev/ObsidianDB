
Чтобы описать желаемую конфигурацию устройств, а в последствии активировать ansible для автоматической её развёртки, нам нужно создать директорию, в которой будут хранится все наши файлы конфигурации.

### Компоненты

В рабочей директории должен лежать файл `inventory` содержащий информацию об управляемых нодах.
