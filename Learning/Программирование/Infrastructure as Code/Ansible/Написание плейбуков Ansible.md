
### Основные термины

Плейбук (playbook) - список блоков, которые ansible последовательно исполняет.
Плей, блок (play) - список тасков, задач для конкретной группы нод.
Таск (task) - маленькая задача используяющая конкретный моудль для выполнения.
Модуль (module) - код, который ansible запускает на управляемой машины, отвечающий за конкретное действие.
Коллекция (colletction) - совокупность модулей.

### Составление Playbook

Каждый плейбук хранится в своём отдельном файле в формате yaml.
В нём перечисляется список плейев (`- ` - синтаксис списка в yaml).

Пример:
``` yaml
- name: My first play
  hosts: myhosts
  tasks:
   - name: Ping my hosts
     ansible.builtin.ping:

   - name: Print message
     ansible.builtin.debug:
       msg: Hello world
```

### Настройка Play

Основные поля для каждого блока задач это:
*  `name` - название. Оно будет отображаться входе выполнения. Лучше делать осознаными для последующего траблшутинга.
* `hosts` - указывается группа хостов, для которых будут выполнятся следующие задачи
* `become` - принемает булевое значение (yes/no), использовать ли sudo для команд или нет.
* `tasks` - собственно список задач.

###  Создание задачи

у задачи главные два поля:
* `name` - также будет отображаться при выполнении
* и используемый модуль. Обычно он записывается как `коллекция.модуль`, для избежания коллизии. Например в примере используется модули `debug` и `ping` из коллекции `ansible.builtin`.
	* У каждого модуля есть свой уникальный набор полей, который надо смотреть отдельно в документации.

### Использование Playbook

``` yaml
ansible-playbook -i inventory.ini playbook.yaml # запуск плейбука
```
