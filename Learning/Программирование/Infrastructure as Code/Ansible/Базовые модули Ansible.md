
###  Модуль ansible.builtin.file

Работа с файлами на устройстве (в Linux всё файл). Создание, удаление настройка прав на них и т.д.

##### Параметры
* `path` - путь до файла (**обязательно**)
* `state` - состояние файла
	* `absent` - для удаления любого файла. При этом происходит рексурсиваное удаление вложенных директорий (если удаляем директорию). Не ругается если такого файла нет (декларативный стиль, значит ничё делать не надо:) )
	* `directory` - создание директорию, и все родительские директории (если нет)
	* `file` - создаёт файл, или изменяет свойства файла
	* `hard` - создание [[Символические и жёсткие ссылки|hard link]], необходим параметр `src`
	* `link` - создание [[Символические и жёсткие ссылки|sym link]], необходим `src`
* `src` - указание источника ссылки, если используется `state` `hard` или `link`.
* `owner` - указание пользователя владельца файла
* `group` - указание группы для файла
* `mode` - настройка прав на файл, по типу `755`.
