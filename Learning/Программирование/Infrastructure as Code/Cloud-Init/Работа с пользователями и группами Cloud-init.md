
### Создание групп

Группы создаются перед созданием пользователей, поэтому в них должны быть внесены только уже существующие пользователи ОС (новых можно будет добавить в последующем блоке)
``` yaml
#cloud-config
groups:
- admingroup: [root, sys] # новая группа с двумя пользователи
- cloud-users # новая пустая группа
```

### Создание пользователей

Пользователи создаются в блоке `users`, они перечисляются как элементы списка (единственное необходимое поле в каждой записи это `name`, всё остальное опционально):
``` yaml
#cloud-config
users:
- name: newsuper # имя пользователя
  shell: /bin/bash # shell по умолчанию
  primary_group: newsuper # название первичной группы. Должна быть создана
  groups: users, admin # добавить в группы
  passwd: $6$j212wezy$7H/1LT4... # Хэш пароля для аутентификации
  sudo: ALL=(ALL) NOPASSWD:ALL # запись в sudoers. Может быть список
  homedir: /path/to/home # домашняя директория. По умолчанию /home/<name>
  ssh_authorized_keys: # список разрешённых (публичных) ключей для ssh
    - # первый
    - # второй
    - # и т.д.
  lock_passwd: false # разрешить вход по паролю
```
Важно, что по умолчанию `lock_passwd` стоит `true`, т.е. зайти в пользователя по паролю невозможно! Такой вход заблокирован! Это сделано для безопасности, потому что по умолчанию считается что используются ssh ключи. Поэтому даже при указании пароля, он может не работать.
