
Есть унивресальный модуль packages который работает для всех дистрибутивов (он сам адаптируется к особенностям дистрибутива).

`package_update: true` - обновить данные о пакетах (по умолчанию false)
`package_upgrade: true` - обновить пакеты (по умолчанию false)
``` YAML
packages: # Установка пакетов
  - tree
  - screen
  - # и т.д.
```
