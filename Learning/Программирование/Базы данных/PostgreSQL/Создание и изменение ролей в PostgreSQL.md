
В PostgreSQL пользователей называют ролями (это отражается на синтаксисе запросов SQL).
Пользователей можно создать много и для каждого настроить свои уникальные права. В последствии можно дать доступ к ролям только по специальным правилам (см. [[Файл pg_hba.conf]]).

### Создание пользователей

SQL запрос на создание роли выглядит так:
``` SQL
CREATE ROLE user_name WITH [ FLAG1 FLAG2 ... ]
```

Есть несколько флагов:
* `LOGIN` - за эту роль можно подключится
* `PASSWORD '1234'` - пароль от роли
* `CREATEDB` - она может создавать новые базы данных. При этом по умолчанию он имеет права только на те БД, которые сам создал
* `CREATEROLE` - создавать и изменять роли. Но он не может создать `SUPERUSER` а также повышать до уровная выше себя. Не может менять суперпользователя
* `SUPERUSER` - получает полный доуступ ко всему

### Изменение пользователей

Запросы выглядят так:
``` SQL
ALTER ROLE ilya WITH PASSWORD 'newpass';
ALTER ROLE ilya WITH CREATEDB;
ALTER ROLE ilya WITH NOSUPERUSER;
```
Видно, чтобы отключить некоторый флаг у роли, надо его прописать здесь с приставкой `NO` (как в последнем примере).

### Удаление пользователей

Удаление роли:
``` SQL
DROP ROLE ilya;
```
Но удалить роль, которая является владельцем некоторых объектов нельзя.

### Вспомогательные команды

Смотреть всех пользователей в системе и их флаги можно при помощи команды `\du`.
