
Кластером в PostgreSQL называется отдельная копия сервера оперирующая с базами данных.
Таким образом на одном сервере можно как бы поставить несколько PostgreSQL серверов, которые будут работать по отдельности.
Каждый кластер по сути это отдельный процесс, и отдельный набор баз данных со своими особеностями.

### Инициализация кластера

Инициализация кластера происходит при помощи утилиты `initdb`. Самый главный параметр в ней, это директорию, внутри которой инстенс PostgreSQL будет оперировать.
 ``` bash
 initdb -D /var/lib/pgsql/data
 ```

Дополнительные опции:
* `--data-checksums` - включение использования контрольных сум. В PostgreSQL хранит данные страницами по 8Кб примерно. Включая контрольные суммы, постгрес начинает к каждой странице такую высчитывать, впоследствии можно проверить повреждались ли данные или нет.
* `--encoding=UTF8` - задать кодировку
* `--locale=en_US.UTF-8` - настройка локалей

Это можно сделать от лица любого пользователя и сколько угодно раз в какой угодно папке. Но зачастую используют пользователя `postgres` (просто устоявшееся традиция) и создают кластер в директории `/var/lib/pgsql/data`. 
Также связано это с настройками `systemd` который по умолчанию ожидает использовать для запуска процесса пользователя `postgres` и запускать из директории `/var/lib/pgsql/data`. Конечно это можно настроить если хочется, и это придётся настроить если использовать кастомного пользователя/директорию.

##### Сложности
При создании кластера от лица `postgres` могут начаться пробелмы. Например как войти в этого пользователя? У него пароль не установлен и аутентификация по паролю не пройдёт, но можно зайти от него через root (`su - postgres`), тогда пароль не потребуют. Или вообще `sudo -i -u postgres ...comand...`.
Также, директория в которой мы создаём кластер должна быть доступна для `postgres` чтобы он мог создать там свои файлы.
