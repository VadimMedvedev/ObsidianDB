
Скачиваем соответсующие пакеты `postgresql`.
[[Кластеры в Postgresql|Инициализируем кластер]] от пользователя `postgres` в директории `/var/lib/pgsql/data`.
Теперь надо заупстить процесс яерез systemd:
``` bash
systemctl enable --now postgresql
```
Если всё правильно, то именно этот заранее созданный кластер заупстится от имени пользователя `postgres`.
Можно теперь попробовать подключится (конечно от имени управляющего пользователя):
``` bash
sudo -u postgres psql
```
Если появилась интерактивная среда, то победа - всё работает.
