
**Запрос** к БД (базе данных) — это инструмент для поиска, обработки, добавления, изменения или удаления информации, структурированный запрос, задаваемый системе управления базами данных (СУБД). Основным языком запросов является SQL (Structured Query Language).

Есть несколько типов запросов:
* Запрос на выборку - нахождение нужных записей в таблице (самый часто используемый тип)
* Запросы-действия - запрос на создание, удаление, изменение объектов в БД. Т.е. для управления базой данных.
