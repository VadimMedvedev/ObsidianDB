
### Информация и данные

**Информация** - сведения об окружающем мире и протекающих в нём процессах, воспринимаемые человеком или специальными устройствами.

**Данные** - информация, представленная в форме, прогодной для хранения, обработки и передачи по каналам связи.

При этом представление информации в виде данных может быть не точной, как и наоборот интерпритация данных в информацию может быть неверной. 

### Структуризация данных

Структуризация данных представляет из себя правила по которым данные записываються. Модели, паттерны их построения.

Степени структуризации:
* **Структурированные данные** - организованы по правилам, есть модель их построения. Каждый отдельный элемент в таких данных - это отдельный факт. Пример: базы данных.
* **Слабоструктурированные данные** - гибкая структура, которая может изменяться, нет чётких правил. Пример HTML-страница, XML-документы.
* **Неструктурированные данные** - не имеют структуры. Пример: видео, аудио и т.д.

*Базы данных работают только со структурированными данными!*

### Классы информационных систем

Такие системы можно разделить на несколько видов:
1) **Системы оперативных обработок данных (OLTP-система)**. Она хранит данные в виде одной или нескольких БД. В основном хранит данные, обновлет, поиск и обрабатывает данные.
2) **Системы аналитической обработки данных (OLAP-система).** Данные лежат в хранилищах данных. В основном эти системы хранят данные и помогают их анализировать методами мат статистики и т.д. А также составляение отчётов по ним и т.п.

###  Понятие базы данных

**База данных** - "склад" структурированных и устойчивых данных, предназначенных для многократного и многоцелевого использования.

Под неустойчивыми данными понимаються данные промежуточные, некорректные.

Базды данных должны удовлетворять нескольким правилам для хорошей работы:
* Требования к организации
	1) Неизбыточность
	2) Непротиворечивость
	3) Независимость от приложений
* Требования к управлению
	1) Защита данных
	2) Эффективность доступа для каждого пользователя

##### Неизбыточность
Неизбыточность означает, что при удалении хоть одного куска данных уже теряеться информация о предметной области (т.е. моделируемой нами части реального мира).
Это приводит к ненужному увеличению занимаего пространства на диске, а также удлинение процесса сортировки, поиска и т.д.

##### Непротиворечивость
БД непротиворечива, если все данные в ней удовлетворяют определённым условиям  (отражают свойства данных и дикутуються предметной областью). Т.е. например если мы храним данные о входе системы пользователя, то это время в таблице не может быть отрицательной.

##### Независимость
Возможность изменения базы данных, не изменяя при этом строения приложения, которое использует данную БД.
Основные способы достижения этого:
* Раздельное хранение метаданных (опиасние структуры дазы данных, её таблиц, полей и т.д.), собственно данных и приложений.
* Многоуровневое представление метаданных.
