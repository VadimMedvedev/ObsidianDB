
 Задано конечно числов атрибутов
 $$(A_1, domA_1), ..., (A_n,domA_n)$$
 В общем случае $domA_i$ - это некоторое множество (возможные значения атрибута)
 Отношение $r$ это подмножество деартова произведения всех доменов атрибутов:
 $$r\subseteq domA_1\times...\times domA_n.$$
 Таким образом $r$ - множество строк (кортежей) длины n, где каждый элемент принадлежит соответсвующему домену.

$r$ - это и есть реляционная таблица таблица!

### Схема отношения

Будем обозначать $R$ - это множество всех атрибутов отношения:
$$R(r)=\{A_1,...,A_n\}=A_1...A_n.$$
Оно действительно определяет "схему" конкретной таблицы (отношения) $r$.

Ключом отношения $r$ называется подмножество $K$ схемы отношения $R(r)$ такое, что выполняется свойства:
1) Для люых двух кортежей $i,j\in r$ поля соответсвующие атрибутов из $K$ различаются хотя бы одним знаением, если $i,j$ различны.
2) Не найдётся такого $K'$ подмножества $R(r)$ удовлетворяющего первому свойству, притом $K'\subsetneq K$.

Два отношения $r_1,r_2$ мы будем называть **идентичными по структуре**, если
* $R(r_1)=R(r_2)$
* .

Реляционной базой данных над $R$ называется конечная свовкупность:
$$d(\rho)=\{r_1,...,r_m\}$$
где $\varnothing \neq R_i\subseteq R$ при всех возможных $i=1,...,m$ и
$$R=\bigcup_{i=1}^mR_i.$$

Схема реляционной базы данных называется пара:
$$\rho=\{R_1,...,R_m\}\ \ \ и\ \ \ R.$$
