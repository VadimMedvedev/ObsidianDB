
**СУБД (Системы управления базами данных)** - совокупность языковых и программных стредств созданное для совместного использования пользователями данных.

Основные функции:
* Управление доступом к данным
* Защита данных
* Поддержка целостности данных

### Структуры языковых средств СУБД

* **Язык описания данных (ЯОД**) - язык высокого уровня декларативного типа, предназначенный для описания схемы БД
* **Языки манипулирования данными (ЯМД)** - языки высокого уровня для определения действий над данными
	* **ЯМД навигационного типа** - процедурный язык для разработки приложений.
	* **ЯМД спецификационного типа** - язык запросов.
		* SQL - структурированный язык запросов
		* QBE - Запросы по образцу (для обычных пользователей, не язык программирования). GQBE - графический вариант. Но такие запросы всё равно переводяться в SQL запросы.

### Классификация СУБД

Модели данных различаються в нескольких моментах:
* Структурная компонента
* Манипуляционная компонента
* Целостаная компонента

Основные модели данных:
1) Реляционные
2) Иерархические - устаревшая, хранили данные в виде деревье и т.д.
3) Сетевые - что-то тоже на устаревшем
4) Объектно-ориентированные - хранит всё как классы и объекты
5) Объектно-реляционные - помесь реляционных и объектно-ориентированных
6) Многомерные - хранит в виде кубов?
7) Нереляционные - не сильно связанные между собой данные

Можно различать СУБД также по характеру использования:
* Многопользовательские - для приложений и работы в сети
* Однопользовательские - обычно используються для личных целей, всё юзерфрендли

По степени распределённости:
1) Локальные СУБД - данные только на локальном компе
2) Распределённые СУБД - на нескольких

### Этапы жизненного цикла базы данных

**Жизненный цикл** - процесс от задумки, до полного ухода из эксплуатации. Т.е. процесс разработки, поддержка и т.д.

Этапы:
1) Системный анализ предметной области
2) Семантическое проектирование
3) Выбор модели данных в СУБД
4) Логическое проектирование
5) Физическое проектирование
6) Реализация БД - создание, загрузка данных, тестирование и разработка приложения
7) Эксплуатация и сопровождение
