
В базах данных используются следующие объекты (все вместе они называются ROUTINES (хранимые программные объекты MySQL)):
* Процедуры - блок кода на SQL. Эта как некоторая функция, которая совмещает себе несколько действий 
* Функции
* События
* Тригеры

### Работа с  процедурами

``` SQL
CREATE PROCEDURE provecure_name([[IN | OUT | INOUT] in_param TYPE, ...])
BEGIN
	-- SQL запросы
END
```

Вызов процедуры
```
CALL pr_name(value1, value2, ...);
```

### Работа с функциями

Мы уже пользовались функциями!! Например MAX, MIN, AVG и т.д. Это всё функции, и их можно задавать самостоятельно.

``` SQL
CREATE FUNCTION name(param1 TYPE, param2 TYPE, ...)
RETURNS TYPE
BEGIN
	-- SQL запросы
END
```

По сути процедуры и функции не сильно отличаются. Но у функции обязательно есть результат и он один, который возвращается (т.е. ставится на место вызова).

### Тригеры

``` SQL
CREATE TRIGGER name
{{BEFORE|AFTER} <OPERATOR> ON <таблица>}
[FOR EACH ROW]
BEGIN
	-- SQL запросы
END
```

Это по сути процедуры, которые мы говорим когда исполнять. Они автоматически будут применятся.
FOR EACH ROW говорит, что будет применятся код к каждой изменяемой/удаляемой/добавляемой и т.д. строке. Параметры старой строки можно посмотреть как `OLD.atribut`, а которая появится `NEW.atribut` (например при обновлении).

### Циклы, переменные и условия

В Процедурах, функциях и тригерах можно использовать циклы и условия.

Работа с переменными
```
DECLARE name TYPE; # объявление переменной
SET name = value; # Значение переменной
```
Потом они могут выводиться (если указаны как выводимые переменные)


Условия:
```
IF условие
THEN
	-- блок кода
END IF;
```
