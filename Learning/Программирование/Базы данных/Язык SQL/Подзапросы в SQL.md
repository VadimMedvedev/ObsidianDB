
Подзапросы указываются в `()`, в них указывается запрос с `SELECT` и его результат будет подставляться на это место как список (по этому надо указывать одно поле для вывода у подзапроса). Если результат единственная запись, то оно будет восприниматься как число. Их можно использовать хоть где. Внутри подзапроса можно использовать поля, записи, при которой используется этот подзапрос (ну как в програмировании i оно будет для каждого подзапроса новое. Подзапрос же делается по новой для каждой новой записи запроса).

Примеры:

``` SQL
SELECT * FROM Products
WHERE Price > (SELECT AVG(Price) FROM Products)
```
