
Виды:
* на создание объекта БД
* добавление записей
* модицикация таблицы
* обновление данных
* удаление данных
* удаление объектов БД


Можно разделить на 4 группы:
* работа со структурой
* работа с данными
* устанавление прав доступа
* управление транзакциями

Операторы:
`CREATE <название объекта>` - создаёт объект (TABLE, VIEW, CURSOR, TRIGGER FUNCTION и т.д.)
`INSERT INTO` - добавление записи в таблицу
`UPDATE` - одновление значения в поле
`ALTER TABLE` - модификация таблицы
`DELETE` - удаление
`TRUNCATE TABLE` - очистка таблицы
