
Транзация это некоторая последовательность операций (набор операторов) которые как бы объединяются в один кусок. Они становятся одной выполняемой единицей. Самое важное свойство транзакции: если хотя бы одна транзакция не сработала, то всё отменяется (откатывается). 
Транзакции по сути являются реализацией принципа ACID.

``` SQL
START TRANSACTION;

-- SQL запросы

COMMIT; -- для применения, окончания транзакции (только если прошлые все прошли успешно)
```

`ROLLBACK;` - оператор позволяет отменить действие всей транзакции по своей воле
