
Вложенный запрос - запрос на выборку, который лежит в другом запросе.
Во вложенных запросах тоже могут быть вложенные запросы.

### Предикат IN

Предикат in можно использовать для вложенных запросов:
``` SQL
SELECT list FROM table1
WHERE field1 IN
	(SELECT field1
	 FROM table2
	 WHERE condition)
```

### Предикаты ALL, ANY, SOME

Синтаксис
``` SQL
field {> | < | ...} {ALL | ANY | SOME} (subquery)
```
Это условие интерпретируется так:
*field больше (или другой оператор) всех (ALL, ANY) значений в таблице (получаемой из подзапроса)*

### Предикат EXISTS

EXISTS - больше некоторого. true если существуют записи в таблице (получаемой из подзапроса).
