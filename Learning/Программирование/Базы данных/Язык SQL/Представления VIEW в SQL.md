
Создание представления
```SQL
CREATE VIEW name AS
{SELECT запрос}
```

**Каждый раз при обращении к представлению выполняется запрос заново**.
Представление (VIEW) в SQL — это **не материализованная таблица**, а сохранённый текст запроса. Когда вы обращаетесь к представлению, база данных выполняет лежащий в его основе SELECT-запрос и возвращает актуальные данные на текущий момент.
